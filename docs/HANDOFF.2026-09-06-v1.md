## 15. ปลายทางของโปรเจกต์ — flow เต็ม

เป้าหมาย (BSOT §13): *ลูกค้าสั่งบนเว็บ → แอดมินตรวจออเดอร์+เงิน → อนุมัติ → ส่งเข้าคลัง/Shipnity โดยไม่ต้องคีย์ซ้ำ*

| ขั้น | ทำได้แล้ว? |
|---|---|
| ลูกค้าดูสินค้า/ราคา/สต๊อกจริง | ✅ (ProductMaster 22 + legacy ~45) |
| หยิบใส่ตะกร้า | ✅ เฉพาะ ProductMaster · ❌ legacy |
| ยืนยันตัวตนด้วยเบอร์ | 🟡 ทำงาน แต่ไม่ส่ง SMS จริง |
| กรอก/เลือกที่อยู่ | ✅ |
| สั่งซื้อ ได้เลขออเดอร์ | ✅ |
| ลูกค้าเห็นวิธีโอน/QR | ❌ (ให้ทัก LINE) |
| ลูกค้าแจ้งว่าโอนแล้ว | ✅ ปุ่มมี บันทึกลง DB |
| แอดมินเห็นออเดอร์+หลักฐาน | ❌ ไม่มีหน้าแอดมิน |
| แอดมินอนุมัติ/เปลี่ยนสถานะ | ❌ (โค้ด `order-status.ts` มี state machine แล้ว แต่ไม่มี UI) |
| ส่งเข้า Shipnity อัตโนมัติ | ❌ จดคิวรอคีย์มือ |
| ลูกค้าเห็นเลขพัสดุ | ❌ |
| เว็บออนไลน์จริงบนโดเมนจริง | ❌ |
