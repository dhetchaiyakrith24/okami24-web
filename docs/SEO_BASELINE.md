## รอบ SEO ก เปลี่ยนอะไรที่น่าจะขยับตัวเลขข้างบน (6 ข้อ)

1. หน้าแรกได้ JSON-LD Organization + WebSite เป็นครั้งแรก (ก่อนหน้านี้ "ไม่มี" ตามบรรทัดสุดท้ายข้างบน) — น่าจะช่วยแก้ปัญหา "okm = ไม่มีข้อมูลเลย" เพราะ `alternateName` ผูก "OKM" กับชื่อร้านแล้ว
2. title หน้าแรกเปลี่ยนเป็น "OKami24 (OKM) — พอตของแท้ ราคาตรง บริการจริง" — ผูกคำ "OKM" และ "พอต" เข้ากับ title ตรง ๆ
3. หน้าแบรนด์ RELX และ SALTHUB (สองหน้าที่ CTR ต่ำสุดในตาราง: 2.9% และ 4.3%) เปลี่ยน title ให้มีชื่อรุ่น + ราคาจริง (เช่น "พอต RELX Smash Go 12K ของแท้ ฿299") แทนคำกว้าง ๆ "ของแท้ทุกรุ่นที่ร้านมี" ที่ไม่ตอบว่าร้านมีรุ่นไหนบ้าง
4. m-bar-15k (คำค้น "m bar 15k / mbar 15k / marbo" ติดอันดับ 3–5 แต่ 0 คลิกในตารางบน) ได้ description ใหม่ที่มีราคา ฿349 และคำว่า "Marbo" ตรง ๆ — เดิม desc ไม่มีราคาเลย
5. Rich Results 7 error "ต้องระบุ offers" ที่เห็นในตารางบนเป็นปัญหาจากรอบราคา (แก้ไปแล้วก่อนรอบนี้) ส่วน warning shippingDetails/hasMerchantReturnPolicy 2 จุด ที่ยังค้าง — รอบ SEO ก เติมให้ครบทั้ง 53/53 offer แล้ว ต้องกด "ตรวจสอบว่าแก้ไขแล้ว" (validate fix) ใน GSC ถึงจะปิดจริง
6. ทุกหน้าสินค้า (53/53) ได้บรรทัดราคาต่อท้าย description ครั้งแรก ("ของแท้ ราคา ฿… สั่งทาง LINE @okm24") — ก่อนหน้านี้ description สินค้าส่วนใหญ่ไม่มีราคาเลย ซึ่งน่าจะเป็นเหตุผลที่คำค้นแบบ "…ราคา" (เช่น caliburn g5 ราคา) ติดอันดับดีแต่ CTR ยังต่ำ
