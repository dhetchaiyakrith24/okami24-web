# เว็บทดสอบสำหรับคนทดสอบภายนอก (Render บริการที่ 2)

เขียน 10/11 · พี่กดเองทั้งหมดในหน้า Render และ Google · Friday ไม่เข้าบัญชีของพี่ · **ห้ามวางรหัสลับใด ๆ ลงไฟล์นี้หรือในแชท**

**เว็บทดสอบคืออะไร:** สำเนาของ okami24.store อีกเครื่องหนึ่ง ข้อมูลทั้งหมดเป็นของปลอม (ลูกค้าปลอม ออเดอร์ปลอมครบทุกสถานะ สลิปปลอม) ·
ทุกหน้ามีแถบเหลือง **"เว็บทดสอบ — ไม่ใช่ร้านจริง"** · Google ไม่เก็บเข้าผลค้นหา · ไม่ส่งอะไรออกไปข้างนอกเลย (ไม่แจ้งกลุ่มไลน์ทีม · ไม่ใช้โควตา EasySlip ·
ไม่ส่งออเดอร์เข้าคลัง Shipnity · ไม่สำรองข้อมูลเข้าที่เก็บของร้าน) · หน้าโอนเงินโชว์**บัญชีปลอม** ไม่มี QR จริง จึงไม่มีใครโอนเงินจริงเข้าร้านจากเว็บนี้ได้ ·
ตะกร้าเปิดเฉพาะเว็บทดสอบ (เว็บจริงยังปิดเหมือนเดิม) · เปิดเครื่องใหม่ทุกครั้ง ข้อมูลกลับเป็นชุดปลอมชุดเดิม (ไม่มีดิสก์ — ตั้งใจ)

**ค่าใช้จ่าย:** เครื่อง Starter **$7/เดือน** (ราว 250 บาท) คิดตามวันที่เปิดใช้ · ลบเครื่องเมื่อทดสอบจบ = หยุดคิดเงิน (ข้อ 5) ·
ไม่ต้องเพิ่มดิสก์ (ไม่เสีย $0.25)

**ทำหลัง Friday บอกว่า "โค้ดเว็บทดสอบขึ้น main แล้ว"** (ก่อนนั้นเครื่องจะขึ้นมาเป็นร้านเปล่า ๆ ไม่มีแถบเหลือง)

## 1. ทำกุญแจ Google สำหรับเว็บทดสอบ (10 นาที)

ใช้ล็อกอินเป็น**ลูกค้า แอดมิน และเจ้าของ**บนเว็บทดสอบ · ทำกุญแจแยกจากของเว็บจริง จะได้ลบทิ้งได้ทีหลังโดยไม่แตะเว็บจริง

1. คอมเปิด https://console.cloud.google.com → เลือกโปรเจกต์ **okami24-gsc** (มุมซ้ายบน)
2. เมนูซ้าย **Google Auth Platform** → **Clients** → **+ Create client**
3. Application type = **Web application** · Name = `OKami24 TEST site`
4. **Authorized redirect URIs** → **+ Add URI** → พิมพ์ `https://okami24-test.onrender.com/api/auth/google/callback`
   (ถ้าข้อ 2.4 ข้างล่าง Render ให้ที่อยู่ไม่ตรงชื่อนี้ = กลับมาแก้บรรทัดนี้ให้ตรงที่อยู่ที่ได้จริง)
5. กด **Create** → หน้าต่างขึ้น **Client ID** และ **Client secret** → **เปิดหน้าต่างนี้ค้างไว้** แล้วไปข้อ 2 (secret ดูได้ครั้งเดียว ·
   ถ้าเผลอปิด = เข้า client นี้ → **Add secret**)

## 2. สร้างเครื่องที่ Render (10 นาที + รอ build 10–15 นาที)

1. https://dashboard.render.com → **+ New** → **Web Service**
2. เลือก repo **okami24-web** → กด **Connect**
3. กรอกตามตารางนี้ (ช่องที่ไม่ได้บอก ปล่อยค่าเดิม):

| ช่อง | ใส่ |
|---|---|
| Name | `okami24-test` |
| Branch | `main` |
| Region | **Singapore** |
| Language / Runtime | Node |
| Build Command | `npm ci && node scripts/build-native-sqlite.js && node scripts/check-native-sqlite.js && npm run build` (ตัวเดียวกับเว็บจริง) |
| Start Command | `npm start` |
| Instance Type | **Starter** ($7) |
| Health Check Path | `/` |
| Auto-Deploy | **Off** (เว็บทดสอบไม่เปลี่ยนกลางคันระหว่างคนทดสอบทำงาน · อยากได้โค้ดล่าสุด = ข้อ 4) |
| Disk | **ไม่ต้องเพิ่ม** |

4. ดูที่อยู่เครื่องที่ Render บอก (ใต้ชื่อด้านบน เช่น `https://okami24-test.onrender.com`) — **ถ้าไม่ใช่ชื่อนี้เป๊ะ** ใช้ที่อยู่ที่ได้จริงแทนในแถว `SITE_URL` ข้างล่าง และในข้อ 1.4
5. หัวข้อ **Environment Variables** → **+ Add Environment Variable** ทีละแถว (ชื่อ Key พิมพ์ตรงตัวอักษร):

| Key | Value |
|---|---|
| `OKAMI24_TEST_SITE` | `on` — **แถวสำคัญที่สุด** ไม่มีแถวนี้ = เครื่องนี้ไม่ใช่เว็บทดสอบ (ไม่มีแถบเหลือง Google อาจเก็บ) |
| `SITE_URL` | `https://okami24-test.onrender.com` (ที่อยู่จากข้อ 2.4 · **ห้ามใส่ okami24.store** — ใส่แล้วเครื่องจะไม่ยอม build ตั้งใจกันพลาด) |
| `OKAMI24_ORDERING` | `on` (เปิดตะกร้าเฉพาะเครื่องนี้) |
| `NODE_VERSION` | `24.14.1` |
| `TZ` | `Asia/Bangkok` |
| `OKAMI24_BACKUP_DISABLED` | `1` (ข้อมูลปลอม ไม่ต้องสำรอง) |
| `OKAMI24_GOOGLE_CLIENT_ID` | Client ID จากข้อ 1.5 |
| `OKAMI24_GOOGLE_CLIENT_SECRET` | Client secret จากข้อ 1.5 |
| `OKAMI24_OWNER_GOOGLE_EMAIL` | Gmail **ของคนทดสอบ** (เป็น "เจ้าของ" บนเว็บทดสอบเท่านั้น · เว็บจริงไม่เกี่ยว) |
| `OKAMI24_STAFF_PASSWORD` | รหัสแอดมินทดสอบ — พี่ตั้งเอง ยาว 12 ตัวขึ้นไป **อย่าใช้รหัสทีมของเว็บจริง** · ส่งให้คนทดสอบแยกข้อความ |

   **ห้ามเพิ่มแถวพวกนี้** (ถึงเผลอใส่ เว็บทดสอบก็ไม่ใช้ แต่อย่าใส่): `OKAMI24_LINE_CHANNEL_SECRET` · `OKAMI24_LINE_CHANNEL_TOKEN` ·
   `OKAMI24_EASYSLIP_API_KEY` · `OKAMI24_OFFSITE_*` · `OKAMI24_PROMPTPAY_QR_BASE64` · `OKAMI24_LINE_LOGIN_*` · `OKAMI24_DATA_DIR` · `OKAMI24_BACKUP_DIR`
6. กด **Deploy Web Service** → รอจนขึ้น **Live** สีเขียว (10–15 นาที · build ล้มเพราะแรมไม่พอ = บอก Friday)

## 3. ลองเอง (เห็นแบบนี้ = สำเร็จ)

1. Render → okami24-test → **Logs** → มีบรรทัด `[test-site] fake data written: 13 orders`
2. มือถือเปิดที่อยู่เครื่อง → **ทุกหน้ามีแถบเหลือง "เว็บทดสอบ — ไม่ใช่ร้านจริง"** ด้านบน · กดใส่ตะกร้าได้
3. เปิด `<ที่อยู่เครื่อง>/robots.txt` → เห็น `Disallow: /` (Google ห้ามเข้า)
4. เปิด `<ที่อยู่เครื่อง>/staff` → ใส่รหัสแอดมินทดสอบ → รายการออเดอร์มีออเดอร์ของ "ลูกค้าทดสอบ 01…08" หลายสถานะ
5. เปิด https://okami24.store บนมือถือ → **ไม่มีแถบเหลือง** ตะกร้ายังปิด = เว็บจริงไม่ถูกแตะ

ไม่ผ่านข้อไหน = แคปหน้าจอ (ปิดส่วนที่เป็นรหัส) ส่ง Friday

## 4. อยากให้เว็บทดสอบได้โค้ดล่าสุด

Render → okami24-test → **Manual Deploy** → **Deploy latest commit** · ข้อมูลกลับเป็นชุดปลอมชุดแรก (ออเดอร์ที่คนทดสอบสั่งไว้หาย) — บอกคนทดสอบก่อนกด

## 5. ทดสอบจบ — ลบเครื่องและกุญแจ (5 นาที)

1. Render → okami24-test → **Settings** → เลื่อนล่างสุด → **Delete Web Service** → พิมพ์ชื่อตามที่หน้าจอขอ → ยืนยัน (หยุดคิดเงินทันที · ข้อมูลปลอมหายหมด — ตั้งใจ)
2. Google Cloud → okami24-gsc → Google Auth Platform → Clients → **OKami24 TEST site** → ลบ (client ของเว็บจริง "OKami24 website sign-in" **ห้ามลบ**)
3. เปลี่ยนรหัสแอดมินทดสอบไม่ต้องทำ — มันอยู่แค่ในเครื่องที่ลบไปแล้ว

## ส่งให้คนทดสอบ (พี่ก๊อปส่งได้ · รหัสส่งแยกข้อความ)

- **ลิงก์เว็บทดสอบ:** `<ที่อยู่เครื่องจากข้อ 2.4>` · เว็บจริง okami24.store **ห้ามทดสอบ**
- **บัญชีลูกค้า:** สมัครเองที่หน้า เข้าสู่ระบบ ด้วย Google หรือสั่งแบบไม่ล็อกอิน (ใส่เบอร์อะไรก็ได้ เว็บไม่ส่ง SMS)
- **บัญชีแอดมิน:** `<ที่อยู่>/staff` → รหัสแอดมินทดสอบ (ส่งแยก) · อยากลองบัญชีแอดมินรายคน = ล็อกอินเป็นเจ้าของ แล้วเพิ่ม Gmail อีกอันของตัวเองที่หน้า **ทีมงาน**
- **บัญชีเจ้าของ:** `<ที่อยู่>/staff/owner` → ล็อกอิน Google ด้วย Gmail ที่แจ้งพี่ไว้
- **วิธีจ่ายเงินทดสอบ:** สั่งของ → หน้าออเดอร์โชว์ **บัญชีปลอม** (ห้ามโอนเงินจริง) → แนบรูปอะไรก็ได้เป็น "สลิป" → ออเดอร์ขึ้น "แจ้งชำระเงินแล้ว — ยังไม่ได้ตรวจ"
  (เว็บทดสอบไม่ต่อระบบตรวจสลิปจริง) → แอดมินกดยืนยันยอดเอง แล้วเดินสถานะต่อจนจัดส่ง/สำเร็จ
- **ข้อมูลในเว็บ:** ลูกค้า ออเดอร์ สลิปทั้งหมดเป็นของปลอม · สินค้าและราคาเป็นของจริงจากเว็บร้าน · ทำอะไรก็ได้ ไม่กระทบร้านจริง ·
  เครื่องเริ่มใหม่เมื่อไหร่ ข้อมูลกลับเป็นชุดแรก
- **สิ่งที่เว็บทดสอบตั้งใจปิดไว้ (ไม่ใช่บั๊ก):** แจ้งเตือนกลุ่ม LINE ทีม · ตรวจสลิปผ่าน EasySlip · ส่งออเดอร์เข้าคลัง Shipnity · ล็อกอินด้วย LINE · รูป QR พร้อมเพย์
