# คู่มือเจ้าของ: ส่วนเจ้าของในหลังบ้าน

หน้านี้เปิดได้เฉพาะบัญชี Google ของพี่ · รหัสทีมงานเปิดไม่ได้ · ทุนและกำไรอยู่ที่นี่ที่เดียว

## เข้าใช้

1. เปิด `https://okami24.store/staff/owner` บนมือถือ แล้วบันทึกเป็นบุ๊กมาร์ก
2. กด **เข้าสู่ระบบด้วย Google** แล้วเลือกบัญชีของพี่
3. เห็นยอดขายวันนี้ = สำเร็จ · อยู่ในระบบได้ 14 วัน แล้วกดเข้าใหม่
4. ถ้าขึ้น "บัญชีนี้เข้าส่วนเจ้าของไม่ได้" = เลือกบัญชีผิด กดใหม่แล้วเลือกบัญชีที่ถูก

## อ่านหน้าเจ้าของ

หน้าแรกมี 3 มุมมอง กดปุ่มด้านบนเพื่อสลับ · บนคอมเห็นพร้อมกัน

- **วันนี้:** ยอดขาย แตะกราฟเพื่อดูแต่ละวัน · กำไรเว็บ · งานค้างและเลขพัสดุ · สต็อก · รายวันย้อนหลัง 14 วัน แตะวันเพื่อดูออเดอร์กับสลิป
- **สัปดาห์:** กำไรรอบล่าสุด · ยอดชำระคลัง · ยอดขาย 7 วัน · LINE และตะกร้า · Google
- **ควบคุมร้าน:** สวิตช์ร้าน (หัวข้อข้างล่าง) · ซ่อนสินค้า · เทียบบิล · ตารางทุน · ออกจากระบบ

กำไร LINE มีเฉพาะรายสัปดาห์หลังเทียบบิล จึงไม่มีช่องกำไรรวมรายวัน · ช่องที่ขึ้นว่ายังไม่มีข้อมูล = ระบบยังไม่รู้ ไม่ใช่ศูนย์

## อัปเดตทุน (เมื่อไฟล์ทุนเปลี่ยน)

1. หน้าส่วนเจ้าของ → **ตารางทุน**
2. เลือกไฟล์ Excel ทุน แล้วกด **อ่านไฟล์**
3. ดูรายการที่เปลี่ยน ตรงที่คิดไว้แล้วกด **บันทึก**
4. ขึ้น "บันทึกแล้ว" = สำเร็จ · ออเดอร์เก่ายังใช้ทุนของวันนั้น

ด้านล่างหน้าบอกสินค้าที่ยังไม่มีทุน ออเดอร์ของรุ่นเหล่านี้จะขึ้นเตือนและไม่นับกำไร

## เทียบบิลทุกเสาร์

1. หน้าส่วนเจ้าของ → **เทียบบิลคลัง**
2. เลือกไฟล์บิลคลัง และไฟล์เรตของรอบเดียวกัน
3. ดูวันเวลาเริ่มและจบรอบ ระบบใส่เสาร์ 13:00 ถึงเสาร์ 13:00 ให้แล้ว
4. กด **เทียบบิล** แล้วจะเห็นกำไรรวม เว็บ LINE และจุดไม่ตรง

เทียบรอบเดิมซ้ำได้ ผลใหม่แทนผลเก่า · ไฟล์ไม่ถูกเก็บ เก็บแค่ผลที่เทียบ

## สวิตช์ร้าน

อยู่ในหน้าส่วนเจ้าของ แตะ **ควบคุมร้าน** ด้านบน (บนคอมอยู่คอลัมน์ขวา) · กดสวิตช์แล้วระบบถามยืนยันก่อนทุกครั้ง · มีผลกับเว็บภายในไม่กี่วินาที ไม่ต้องรอขึ้นเว็บใหม่

**ปิดตะกร้า**
- ลูกค้ายังดูสินค้าและราคาได้ตามปกติ แต่สั่งบนเว็บไม่ได้ ปุ่มซื้อบนหน้าสินค้ากลายเป็นปุ่ม "สั่งซื้อทางไลน์"
- ลูกค้าที่เปิดตะกร้าหรือหน้าชำระเงินค้างไว้ จะถูกพาไปหน้าสินค้าที่มีข้อความชวนสั่งทาง LINE
- ออเดอร์ที่สั่งแล้ว การแนบสลิป และหน้าติดตามออเดอร์ ยังใช้ได้ตามปกติ
- ไอคอนตะกร้าบนหัวเว็บยังขึ้นอยู่ กดแล้วจะไปหน้าสั่งทาง LINE

**ปิดเว็บชั่วคราว**
- ลูกค้าที่เข้าเว็บจะเห็นหน้า "ปิดปรับปรุงชั่วคราว" พร้อมปุ่มทักไลน์
- เว็บบอก Google ว่าปิดชั่วคราว ให้กลับมาใหม่ อันดับจึงไม่หาย ถ้าไม่ปิดนานหลายวัน
- ยังใช้ได้ตามปกติ: หลังบ้านของพี่และทีมงาน · บอทตรวจสลิป · คลัง Shipnity ส่งสต็อกและเลขพัสดุเข้ามาได้ · หน้าติดตามออเดอร์และการแนบสลิปของลูกค้าเดิม · หน้าเข้าสู่ระบบ

**ซ่อนสินค้า**
- พิมพ์ชื่อรุ่นในช่องค้นหา แล้วกด **ซ่อน**
- หน้าสินค้านั้นขึ้น "ไม่พบหน้านี้" การ์ดหายจากหน้ารวมสินค้าและหน้าแรก และใส่ตะกร้าไม่ได้ แม้ลูกค้าเปิดหน้าค้างไว้ก่อน
- ที่ยังเห็นชื่ออยู่จนกว่าเว็บจะขึ้นรอบถัดไป: เมนูหัวเว็บ หน้าแรกบางช่อง ตารางเทียบรุ่น บทความ และช่องค้นหา (ขึ้นว่าสินค้าหมด) · จำนวน "รายการ" บนหน้ารวมสินค้ายังนับรวมอยู่

**เปิดกลับ**
- ตะกร้าและเว็บ: กดสวิตช์ตัวเดิมอีกครั้ง แล้วกดยืนยัน
- สินค้า: ในหัวข้อ "ซ่อนอยู่ตอนนี้" กด **เปิดกลับ** ข้างชื่อสินค้า
- ตอนสวิตช์ไหนปิดอยู่ ด้านบนของหน้าวันนี้และสัปดาห์จะมีป้ายเตือน "เว็บปิดอยู่" หรือ "ตะกร้าปิดอยู่" ไว้ ไม่ให้ลืมเปิดกลับ
