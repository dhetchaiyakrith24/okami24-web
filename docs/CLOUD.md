## 2. Javis ส่งคำสั่งถึง Friday บนคลาวด์ — เจ้าของไม่ต้องก๊อป

**ทาง A (หลัก) — ลิงก์เติมคำสั่งให้ + กล่องจดหมาย `inbox`** [ลองแล้ว: ส่วน git · รอ T4: ส่วนเปิดแชท]
1. Javis เปิด GitHub → รีโป okami24-web → เลือก branch **`inbox`** → **Add file → Create new file** → ชื่อ `rounds/<ชื่อรอบ>.txt` → วางคำสั่งรอบทั้งไฟล์ → **Commit changes** (ลงที่ branch `inbox` เท่านั้น ไม่ใช่ main)
2. Javis เปิดลิงก์ (แก้ชื่อไฟล์ท้ายลิงก์):
   `https://claude.ai/code?repositories=dhetchaiyakrith24%2Fokami24-web&prompt=<คำสั่งสั้นที่เข้ารหัสแล้ว>`
   คำสั่งสั้นมาตรฐาน: `อ่าน docs/HANDOFF.md §16 แล้วอ่านไฟล์คำสั่ง: git fetch origin inbox && git show origin/inbox:rounds/<ชื่อไฟล์> แล้ว /round-open`
3. เลือก branch งานในช่องเลือก branch (ถ้ารอบต่อจาก branch ที่ยังไม่ merge) → กด Enter · เสร็จ — เจ้าของไม่ต้องทำอะไร
- ทดสอบฝั่ง git แล้ว: Friday บนคอมสร้าง `inbox` + ไฟล์ทดสอบผ่าน API เดียวกับหน้าเว็บ GitHub แล้วอ่านกลับด้วย git ได้ตรงทุกไบต์ (2026-09-26)
- ข้อจำกัด: ลิงก์ใส่คำสั่งยาว 10–26 KB ตรง ๆ ไม่ได้ (ยาวเกินลิงก์) จึงใช้ `inbox` · `prompt_url` ใช้กับรีโปส่วนตัวไม่ได้ (ต้องเป็นลิงก์สาธารณะ) [เอกสาร]

**ทาง B (ส่งข้อความตามหลัง) — คำสั่งบรรทัดเดียวจากคอมเครื่องไหนก็ได้ที่ล็อกอิน Claude** [เอกสาร · รอ T5]
`claude -p "ข้อความ" --cloud <เลขแชทคลาวด์ หรือลิงก์ claude.ai/code/...>` — ใส่ข้อความเข้าแชทคลาวด์ที่เปิดอยู่แล้ว โดยไม่ต้องเปิดหน้าแชท
- Friday บนคอมใช้ได้ (ลองแล้วว่าเครื่องมือมีคำสั่งนี้) · **สร้างแชทคลาวด์ใหม่** ด้วย `claude --cloud` ต้องมีหน้าต่าง terminal จริง Friday ในแอปทำเองไม่ได้ [ลองแล้ว: ถูกปฏิเสธ "requires an interactive terminal"]
- เบราว์เซอร์ในแอปของ Friday ยังไม่ได้ล็อกอิน claude.ai และ Friday ห้ามล็อกอินเอง → Friday เปิดแชทคลาวด์เองไม่ได้ [ลองแล้ว]
