## 2. Javis ส่งคำสั่งถึง Friday บนคลาวด์ — เจ้าของไม่ต้องก๊อป

**ทาง A (หลัก) — ลิงก์เติมคำสั่งให้ + กล่องจดหมาย `inbox`** [ลองแล้ว — T4 เปิดด้วยทางนี้ 26/09 แชทคลาวด์อ่านไฟล์ใน `inbox` แล้วทำครบ 18 ข้อ]
1. Javis เปิด GitHub → รีโป okami24-web → เลือก branch **`inbox`** → **Add file → Create new file** → ชื่อ `rounds/<ชื่อรอบ>.txt` → วางคำสั่งรอบทั้งไฟล์ → **Commit changes** (ลงที่ branch `inbox` เท่านั้น ไม่ใช่ main)
2. Javis เปิดลิงก์ (แก้ชื่อไฟล์ท้ายลิงก์):
   `https://claude.ai/code?repositories=dhetchaiyakrith24%2Fokami24-web&prompt=<คำสั่งสั้นที่เข้ารหัสแล้ว>`
   คำสั่งสั้นมาตรฐาน: `อ่าน docs/HANDOFF.md §16 แล้วอ่านไฟล์คำสั่ง: git fetch origin inbox && git show origin/inbox:rounds/<ชื่อไฟล์> แล้ว /round-open`
3. เลือก branch งานในช่องเลือก branch (ถ้ารอบต่อจาก branch ที่ยังไม่ merge) → กด Enter · เสร็จ — เจ้าของไม่ต้องทำอะไร
- ข้อจำกัด: ลิงก์ใส่คำสั่งยาว 10–26 KB ตรง ๆ ไม่ได้ (ยาวเกินลิงก์) จึงใช้ `inbox` · `prompt_url` ใช้กับรีโปส่วนตัวไม่ได้ [เอกสาร]
- ผลกลับ: แชทคลาวด์ push ไฟล์ผลขึ้น branch งาน แล้ว Friday บนคอม `git pull` อ่านเอง (T4 ทำแบบนี้ `docs/cloud-results/T4.md`) [ลองแล้ว]

**ทาง B (ส่งข้อความตามหลังเข้าแชทคลาวด์ที่เปิดอยู่)** — ผล T5 (26/09):

- ส่งจากแอป Claude บนคอม (เครื่องมือส่งข้อความข้ามแชท) → **ส่งผิดแชท**: แชทคลาวด์ตัวเดียวในรายชื่อเป็นของงานการ์ตูน ไม่ใช่เว็บ (รายชื่อไม่บอกรีโป) ฝั่งการ์ตูนปฏิเสธ ไม่มีอะไรถูกแตะ [ลองแล้ว · บทเรียน `.claude/LESSONS.md` พ2]

## 3. เปิดรอบบนคลาวด์จากมือถือ (แทน "อ่าน HANDOFF §16 + แนบไฟล์ + /round-open" ของคอม)
