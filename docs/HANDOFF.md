## 8. ความเสี่ยงและจุดต้องระวัง (อันตรายมาก → น้อย)

1. **การสั่งซื้อออนไลน์ปิดไม่มีกำหนด** จนกว่าข้อ 44 ครบ — ทุกยอดขายไปทางไลน์ ทีมรับเอง
2. **ออเดอร์จริง + สำเนาอยู่ดิสก์ก้อนเดียว** (ข้อ 42) — เจ้าของรับความเสี่ยงแล้ว (ทาง 1) จนกว่าจะถึงคิวทาง 2
3. **ข้อยกเว้นมาสก์หัวใจ (ข้อ 21)** — เกณฑ์ "desktop ไม่ขยับ" คือ "0 นอกกล่อง FavoriteButton · ≤2/255 ในกล่อง" · **ห้ามขยายมาสก์** · สคริปต์พิมพ์ขนาดมาสก์ทุกครั้ง
4. **หน้าที่ไม่นิ่งเวลายิงภาพ 1440 (ต้องรู้ก่อนสรุปว่า "desktop ขยับ"):** หน้าแรกมีลูกศร SCROLL animation → ต่าง 56 px ที่กล่อง (715–724, 4030–4041) ทุกครั้ง · หน้า `pdp-with-images` สลับ 2 สภาพ ต่าง ~2% · **วิธีตัดสิน: ยิง baseline ซ้ำโดยไม่แก้โค้ด ถ้าได้กล่องเดิม = ไม่ใช่ความผิดของโค้ด**
5. **ข้อความ JSX ที่ดูไม่มีพิษภัยทำ desktop ขยับได้** — รอบนี้เจอจริง: รวม `{n} {คำ}` เป็นสตริงเดียวทำให้ text node ยุบจาก 3 เหลือ 1 แล้วตัวอักษรขยับ 30 พิกเซลที่ 1440 · **ถ้าจะแตะบรรทัดที่ desktop เห็น ให้เก็บรูปทรง JSX เดิมไว้**
6. **Cowork merge+deploy โดยไม่บอกในแชท** → ก่อนสรุปสถานะเว็บให้ `git fetch` + GET เว็บจริงเสมอ
7. **iOS Safari ต่างจาก headless Chrome จริง** — อาการแถบทับ footer วัดในเครื่องไม่เจอเลย (พ้น 119px) แต่บนเครื่องจริงทับ · **งานมือถือทุกอย่างต้องให้เจ้าของยืนยันบนเครื่องจริง อย่าเชื่อภาพ headless อย่างเดียว**
