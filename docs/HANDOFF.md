## 6. จำเป็นแต่ยังไม่ได้ทำเลย

- **ตัดสินใจเรื่อง deploy** — โค้ดฐานข้อมูลตอนนี้ **ต้องรันบนเครื่องเดียวที่มีดิสก์ถาวร** (VPS/container เดียว) ใช้บน Vercel/serverless **ไม่ได้ ข้อมูลจะหาย** [ตรวจแล้วจริง: คอมเมนต์หัวไฟล์ `src/lib/db/client.ts` เขียนเงื่อนไขนี้ชัดเจน] — ยังไม่มีใครเลือกที่ deploy
- **ไม่มีไฟล์ `.env` ใด ๆ ในโปรเจกต์** [ตรวจแล้วจริง] และ production build **จะปฏิเสธไม่ build ถ้าไม่ตั้ง `SITE_URL`** [ผมเข้าใจว่า: memory เรื่อง `src/lib/seo.ts`] → ต้องมีโดเมนจริงก่อน
- ผู้ให้บริการ SMS OTP · เลขบัญชี/QR รับเงิน · วิธีเชื่อม Shipnity — ทั้งสามอยู่ใน BSOT §19 "Unknowns" ยังไม่มีใครเลือก
- **นโยบายเคลม 7 วันต้องมีวิดีโอแกะกล่อง** (BSOT §12) — ยังไม่ได้ตรวจว่าข้อความบนเว็บพูดตรงกับที่ทำได้จริง [เจ้าของยังไม่ได้ยืนยัน]
- SEO/เนื้อหา — เจ้าของจัดให้เป็นลำดับสุดท้าย [ผมเข้าใจว่า: memory 2026-09-03]

## 8. ความเสี่ยงและจุดต้องระวัง (มากไปน้อย)

1. **repo นี้ไม่มี remote เลย** [ตรวจแล้วจริง: `git remote -v` ว่างเปล่า] — งานทั้งหมด commit แล้ว (§10) แต่สำเนาเดียวในโลกอยู่ในเครื่องนี้ ถ้าดิสก์พัง = หายหมด → เจ้าของควรตั้ง remote (GitHub private ฯลฯ) แล้ว push เอง (AI ห้าม push โดยไม่ได้รับอนุญาต)
2. **ฐานข้อมูลอยู่ในโฟลเดอร์ `.data/` เครื่องเดียว** — deploy ผิดแพลตฟอร์ม = ออเดอร์ลูกค้าหาย (ดูข้อ 6)
3. **มีข้อมูลทดสอบค้างใน `.data/okami24.db`** (เบอร์ 0812345678, "Somchai Test", ออเดอร์ทดสอบ) — ห้ามเอาไฟล์นี้ไปใช้จริง ต้องเริ่มฐานข้อมูลใหม่ตอน deploy
4. **โค้ด SQL เป็นแบบ SQLite เฉพาะ** — ถ้าวันหน้าจะย้ายไป Postgres ต้องเขียน SQL ใหม่ ไม่ใช่แค่สลับไดรเวอร์ [ตรวจแล้วจริง: คอมเมนต์ใน `client.ts` แก้คำอ้างเดิมที่บอกว่าง่ายไว้แล้ว]
5. **รูป VOOPOO "ทางการ" หลายรูปเป็นภาพ AI** — ก่อนใช้รูปจาก shop.voopoo.com ต้อง grep คำว่า `AIGC` ในไฟล์ก่อนทุกครั้ง [ผมเข้าใจว่า: memory 2026-09-04]
6. **`docs/PROJECT_HANDOFF.md` ล้าสมัย** — ถ้า AI ตัวใหม่อ่านเจอก่อนไฟล์นี้จะเข้าใจผิดว่า ProductMaster ยังไม่ต่อกับหน้าเว็บ
7. **ข้อจำกัดเครื่องมือของเซสชัน (ไม่ใช่บั๊กโปรเจกต์):** (ก) Browser pane ของ Claude คลิกปุ่มที่อยู่นอกจอไม่ติด — ต้อง `scroll_to` ก่อนคลิกทุกครั้ง ไม่งั้นจะคิดว่าฟอร์มพัง ทั้งที่ไม่พัง (เจอในเซสชันนี้ 3 รอบ) (ข) Browser pane อ่านหน้าเว็บร้านบุหรี่ไฟฟ้าไม่ได้ ("Policy check unavailable") — ใช้ `curl` แทน (ค) Chrome headless ย่อหน้าต่างแคบกว่า ~500px ไม่ได้ ต้องใช้หน้าห่อ iframe ถ้าจะแคปมือถือเป็นไฟล์

## 13. แนะนำทำอะไรต่อ (เรียงลำดับ)

1. ~~commit งานค้าง~~ **ทำแล้ว** (§10) → ถัดไปคือ **สำรองออกจากเครื่อง** — ถ้ามี remote ให้เจ้าของสั่ง push เอง (AI ห้าม push เองตามกฎ) ถ้ายังไม่มี remote ให้ตั้งก่อน
2. **ให้เจ้าของเปิดดูไหลตะกร้า→สั่งซื้อจริงในเบราว์เซอร์แล้วให้ความเห็น** — ตอนนี้ผ่านแค่ QC เทคนิค ยังไม่มีการอนุมัติจากเจ้าของ ถ้าทิศทางผิดจะได้รู้ก่อนต่อยอด
3. **ตัดสินใจ 3 เรื่องที่บล็อกการเปิดจริง: ที่ deploy / เลขบัญชีรับเงิน / โดเมน** — โค้ดพร้อมรอแค่ข้อมูล
4. **หน้าแอดมินดูออเดอร์แบบง่ายที่สุด** (รายการ + เปลี่ยนสถานะ + ดูหลักฐานโอน) — เป็น "ผลที่เห็นได้ใน 7–14 วัน" ที่ทำให้ระบบสั่งซื้อใช้ได้จริงกับทีม 2 คน
5. ถัดไปค่อยเป็น SMS จริง / Shipnity จริง / รูป Unbranded ที่เหลือ / cinematic
