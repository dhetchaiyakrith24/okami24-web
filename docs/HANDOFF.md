## 4. ยังไม่ได้แก้ (รู้ว่าขาด แต่ยังไม่ได้ทำ)

1. **งานรูปสินค้าขายดี 12 ตัว — ยังไม่ได้ทำรูปเลยสักใบ** (ดู §5 สำหรับสิ่งที่พร้อมแล้ว)
2. **หน้าแอดมิน** (ข้อ 1) — **เจ้าของสั่งทดไว้ ห้ามแตะ ห้ามถามซ้ำ**
3. **เจ้าของยังไม่ได้สแกน QR ที่ครอปใหม่** (ข้อ 8) — งานครบแล้ว เหลือเอามือถือสแกนทดสอบ ถ้าสแกนไม่ติดให้คัดลอก `promptpay-qr-fullslip.png` ทับกลับ

5. **swatch สีดำมองไม่เห็นบนพื้นดำ** — งาน UI เล็ก ยังไม่ทำ
6. **ฐานข้อมูลมีข้อมูลทดสอบ** (ออเดอร์ 3) — ต้องเริ่ม DB ว่างตอน deploy (ข้อ 5)
7. **สคริปต์ยังลดคุณภาพ WebP ต่ำกว่า 82 ได้เอง** (ข้อ 32) — เจ้าของสั่งรายงานก่อน แก้จริง 30 นาที
8. ที่เหลือ 15 เรื่อง "ยังไม่เริ่ม" ตาม LAUNCH_AUDIT

## 8. ความเสี่ยงและจุดต้องระวัง (มากไปน้อย)

1. **เปิดขายวันนี้ ทีมยังไม่มีหน้าจอดูออเดอร์** — ต้องเปิดจากฐานข้อมูลเอง (เจ้าของสั่งทดไว้เอง) · เรื่องรับเงินและ OTP ไม่ขวางแล้ว
2. **ปิด OTP = เบอร์ที่กรอกไม่ได้พิสูจน์ว่าเป็นของคนกรอก** — ตัวป้องกันคือแอดมินตรวจเงินจริงก่อนส่งของ ("จ่ายแล้ว≠ยืนยัน") · เจ้าของรับความเสี่ยงนี้แล้ว เงื่อนไขเปิดกลับ = เจอออเดอร์ผี
3. **QR ที่เสิร์ฟตอนนี้เป็นไฟล์ที่ผมครอปเอง ยังไม่มีใครสแกนทดสอบ** — ถ้าสแกนไม่ติด ลูกค้าจ่ายไม่ได้ · กู้คืนเร็ว: คัดลอก `promptpay-qr-fullslip.png` ทับ `promptpay-qr.png`
4. **เลขบัญชีจริงอยู่ในโค้ด** (`src/data/payment.ts`) และ BSOT — repo private แต่ถ้าเปลี่ยนเป็น public จะหลุด · ชื่อบัญชีเป็นชื่อบุคคล
5. **ไฟล์ QR ทั้ง 2 ไฟล์อยู่นอก git และนอกระบบสำรองอัตโนมัติ** — ย้ายเครื่อง/ขึ้นโฮสต์ต้องคัดลอกเอง (BACKUP.md บอกไว้)
6. **สำรองอยู่เครื่องเดียวกันทั้งหมด** — เครื่องพัง = หายทั้งคู่ รอโฮสต์
7. **หน้าบริการ SSR เป็นอังกฤษก่อนแล้วสลับตามคุกกี้** — Google เห็นเนื้อหาอังกฤษ · จะเปลี่ยนต้องทำระดับเว็บ (ข้อ 30)
8. **บทเรียนเครื่องมือ (ไม่ใช่บั๊กโปรเจกต์):** (ก) เอเจนต์ล้มเพราะโควตาโมเดล — เปิดใหม่และ**ระบุ `model` ให้ตรงกับที่ยังใช้ได้** (designer ล้ม 2 ครั้งเพราะเรื่องนี้) (ข) `SendMessage` หาเอเจนต์เดิมใช้ไม่ได้ (ค) ลบเส้นทางใน `src/app/` แล้ว `tsc` ฟ้องไฟล์ประกาศเก่า → ลบ `.next/types` แล้วโหลดหน้าใหม่ 1 ครั้ง (ง) เปลี่ยนรูปแล้วภาพมือถือยังเก่า → ลบ `.next/cache/images` + `.next/dev/cache/images` (จ) `node -e` ที่มี backtick ในสตริง bash จะโดนกลืน — ใช้ `node --input-type=module -e '...'` (ฉ) dev server ค้างไม่ตอบแต่ยังจอง port → `taskkill //PID <pid> //F` แล้ว `preview_start` ใหม่ · ล็อกอยู่ที่ `.next/dev/lock`
9. `docs/PROJECT_HANDOFF.md` ล้าสมัย · สคริปต์ช่วยงานเก็บใน `_incoming/` หรือ `scripts/`
