1. รัน `git status` + `git log -5 --oneline` + `git remote -v` แล้วเทียบกับเอกสารนี้ — **ถ้าไม่ตรง ให้เชื่อ repo** และแก้เอกสารนี้ · ถ้า `.git` กลับเป็นไฟล์บรรทัดเดียว (worktree pointer) แปลว่ามีอะไรผิด หยุดแล้วบอกเจ้าของ
2. เปิด `docs/LAUNCH_AUDIT.md` ข้อ 1 แล้วเริ่ม**หน้าแอดมิน**ด้วย planner — ส่งทางเลือกวิธีล็อกอินให้เจ้าของเลือกก่อนเขียนโค้ด ไม่ต้องถามว่าจะเริ่มอะไร
3. ก่อน commit ใด ๆ รัน `npm run verify:catalog -- --full` ให้ผ่าน · ทุกงานผ่าน checker ก่อนพูดว่าเสร็จ · จบก้อนแล้ว push
