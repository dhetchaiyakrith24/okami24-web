# คู่มือแอดมิน — ตรวจสลิปโอนเงินบนเว็บร้าน

📌 **ตรวจสลิปลูกค้าบนเว็บร้าน (สำหรับทีมงานเท่านั้น)**

**ลิงก์:** https://okami24.store/staff/slip (หรือเปิด https://okami24.store/staff แล้วกดกล่อง **ตรวจสลิป** ด้านบน · กล่องด้านบนตั้งแต่ 28/10)
รหัสทีมงาน: เจ้าของร้านส่งให้แยกอีกข้อความ — ห้ามส่งต่อให้คนนอก และห้ามบอกลูกค้า

**1. เปิดครั้งแรก**
- กดลิงก์จาก LINE แล้วเลือก **เปิดในเบราว์เซอร์** (Safari หรือ Chrome) จะใช้งานได้ลื่นกว่าเปิดใน LINE
- บันทึกไว้ที่หน้าจอโทรศัพท์ จะได้กดเปิดได้ทันทีครั้งต่อไป
  - iPhone (Safari): กดปุ่มแชร์ ⬆️ → **เพิ่มไปยังหน้าจอโฮม**
  - Android (Chrome): กด ⋮ มุมขวาบน → **เพิ่มลงในหน้าจอหลัก**
- ใส่ **รหัสทีมงาน** → กด **เข้าสู่ระบบ** (อยู่ในระบบได้ 12 ชั่วโมง หลังจากนั้นให้ใส่รหัสใหม่)
- ใส่รหัสผิด 5 ครั้ง ระบบจะพักไว้ 15 นาที

**2. ตรวจสลิป**
1. ลูกค้าส่งสลิปมาใน LINE → กดค้างที่รูป → **บันทึก** ลงเครื่อง
2. ในหน้าตรวจสลิป แตะกล่อง **"แตะเพื่อถ่ายรูป หรือเลือกรูปสลิป"** → เลือกรูปที่บันทึกไว้
3. ถ้ารู้ยอดออเดอร์ ให้ใส่ในช่อง **"ยอดที่ลูกค้าต้องโอน"** ด้วย (ระบบจะเทียบให้) ไม่ใส่ก็ได้
4. กด **ตรวจสลิปนี้** → รอไม่กี่วินาที

**3. อ่านผล**
- **สลิป 1 ใบ ตรวจครั้งเดียวพอ** — ผลครั้งแรกคือผลจริง ไม่ต้องตรวจซ้ำเพื่อความชัวร์
- ✅ **ธนาคารยืนยันสลิปนี้ และเงินเข้าบัญชีของร้าน** → ผ่าน ยืนยันออเดอร์ตามขั้นตอนปกติได้
- ❌ **สลิปนี้เคยตรวจไปแล้ว ห้ามใช้ยืนยันออเดอร์ใหม่** → สลิปใบนี้เคยถูกตรวจแล้ว (ถ้าเคยตรวจจากหน้านี้ จะบอกเวลาที่ตรวจครั้งแรกด้วย) · ถ้าเป็นออเดอร์ใหม่ = ลูกค้าใช้สลิปซ้ำ **อย่ายืนยัน** แจ้งเจ้าของร้าน
- ⚠️ **ระบบบอกไม่ได้ว่าเงินเข้าบัญชีร้านหรือไม่** → ให้เจ้าของร้านดูยอดเข้าในแอปธนาคารของร้านก่อนยืนยัน
- ❌ **เงินเข้าบัญชีอื่น ไม่ใช่บัญชีของร้าน** → **อย่ายืนยัน** สอบถามลูกค้าอย่างสุภาพว่าโอนเข้าบัญชีไหน
- ❌ **ยอดในสลิปไม่ตรงกับยอดออเดอร์** → แจ้งลูกค้าเรื่องยอดที่ขาดหรือเกิน ก่อนยืนยัน
- **ตรวจสลิปนี้ไม่ได้** → ลองรูปที่ชัดกว่า (เห็น QR มุมสลิปครบ แคปหน้าจอดีกว่าถ่ายจากจอ) · ถ้ายังไม่ได้ อาจเป็นสลิปปลอมหรือสลิปเก่าเกินไป → แจ้งเจ้าของร้าน
- **ระบบ EasySlip ไม่ตอบ** หรือ **โควตาหมด** → ให้เจ้าของร้านดูยอดในแอปธนาคารแทน แล้วแจ้งเจ้าของร้าน

**4. ข้อควรรู้**
- หน้านี้ **ช่วยตรวจ** เท่านั้น ไม่ได้ยืนยันออเดอร์ให้ — คนยังเป็นคนยืนยันเหมือนเดิม
- ตรวจได้เดือนละ 1,000 ใบ (ดูตัวเลขบนหน้า) · อัปโหลดสลิปใบเดิมซ้ำไม่เสียโควตา
- สลิปที่ลูกค้าสแกน QR ของร้าน ผู้รับในสลิปจะขึ้นเป็น **"เติมเงินพร้อมเพย์ 004999137680913"** = บัญชีร้าน ระบบรู้จักแล้ว
- ระบบไม่เก็บรูปสลิปไว้ และไม่เก็บชื่อหรือเลขบัญชีของลูกค้า
- ใช้เสร็จแล้วกด **ออกจากระบบ** ท้ายหน้า ถ้าใช้เครื่องร่วมกับคนอื่น

**5. คืนเงินลูกค้า LINE (บอทหักยอดให้เอง · เจ้าของ 10/11)**
- แอดมิน **ทำเหมือนเดิมทุกอย่าง**: โพสต์ "แจ้งยอดโอนคืน…" พร้อมยอด แล้วตามด้วยรูปสลิปที่ลูกค้าโอนมา ในกลุ่ม OKAMI INFORMATION
- บอท OKM ORDER อ่านแค่ **ยอดคืน** กับ **รูปสลิปที่ตามมา** แล้วตอบใต้รูป 1 บรรทัด:
  ↩️ บันทึกคืนเงินแล้ว = ยอดขาย LINE หักให้แล้ว · ↩️ บันทึกไว้แล้ว = โพสต์ซ้ำ ไม่นับซ้ำ · ⚠️ ยังจับคู่ไม่ได้ = ไปจับคู่เองที่หน้าตรวจสลิป
- คืนบางส่วนได้ (เช่น สั่ง 2,600 คืน 1,300) · ข้อความโพสต์มียอดเดียว ใส่เป็น "1,300.-" หรือ "ยอด 1,300 ฿" แบบที่ใช้อยู่
- **จับคู่เอง** (หน้าตรวจสลิป → หัวข้อ "คืนเงินลูกค้า LINE"): ใส่ **เลขอ้างอิง 6 ตัวท้ายสลิปลูกค้า** (ดูได้ในหน้ายอดขาย ตรงสลิปของวันนั้น) แล้วกด "จับคู่"
- คืนเงินที่ไม่ได้โพสต์ในกลุ่ม หรือรายการย้อนหลัง → "ลงคืนเงินเอง": ใส่ยอดคืน + เลขอ้างอิงท้ายสลิป
- กดผิด → "ยกเลิกการจับคู่" ยอดกลับเข้ายอดขายทันที
- ระบบไม่เก็บข้อความโพสต์ ชื่อ หรือเลขบัญชีลูกค้า เก็บแค่ยอดคืน เวลา และสลิปที่คู่กัน
- ต้องตั้งครั้งเดียว: เชิญบอท OKM ORDER เข้ากลุ่ม OKAMI INFORMATION แล้วที่หน้า Okami dev → "ตั้งค่ากลุ่ม LINE ของบอท" กด **ใช้เป็นกลุ่มแจ้งคืนเงิน** ที่กลุ่มนั้น
