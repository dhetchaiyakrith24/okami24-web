## 3. ติดอะไร / สิ่งที่ตัดสินใจเองระหว่างทาง (บอกให้รู้)
- **รูปรส F3 ทางการมีเงา/แสงจางกึ่งโปร่งใสรอบเครื่อง** → เพิ่มตัวเลือก `alphaCut` ในสคริปต์ (ทิ้งพิกเซลที่โปร่งกว่า ~78%) แล้วทำใหม่ทั้งชุด — ขอบเครื่องยังคม ตรวจแล้ว
- **รูป F4 มีโลโก้เทาจางหลังเครื่อง** → เพิ่ม `keepLargestComponent` (เก็บเฉพาะชิ้นใหญ่สุด) — ใช้ได้เฉพาะสินค้าชิ้นเดียว
- เพิ่ม `--force` ให้สคริปต์เพื่อทำซ้ำจากต้นฉบับเดิมด้วยค่าใหม่ (กฎ "ทับเฉพาะเมื่อใหญ่กว่า" ยังเป็นค่าเริ่มต้น)
- IMAGE_AUDIT ตอนแรกไม่นับสินค้าที่ซ่อน (เหลือ "ต้องขอ 2") — แก้ให้นับรวม เพราะสินค้าที่ซ่อน**ยังเป็นช่องว่างที่ต้องหารูป** (ตัวเลขจริงคือ 15)
- ระบบ "ซ่อน" เป็นโครงสร้างใหม่ (แตะ type/schema/index) — ทำแบบเล็กที่สุด: โค้ดหน้าร้านทุกจุดใช้ `allProducts` อยู่แล้วจึงไม่ต้องแก้ 28 ไฟล์ที่เรียกใช้; ตัวตรวจดีดับซ้ำใช้ตัวเต็ม
