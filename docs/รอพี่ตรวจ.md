# รอพี่ตรวจ

พี่ตอบเป็นเลขข้อได้เลย · มีเฉพาะเรื่องที่พี่ต้องตัดสิน ข้อละบรรทัด · ตอบแล้ว Friday ลบออก · งานรูปเสร็จแล้วขึ้นเว็บเลย พี่ดูบนเว็บเอง

## รอพี่ตัดสิน

75. โปรสมาชิก (พี่เสนอ 24/10: ส่งฟรีตั้งแต่ ฿300 + ลด 5% เมื่อครบ ฿1,000) · A = ให้ "ลูกค้าเก่า" (เบอร์ที่เคยได้รับของแล้ว ≥1 ครั้ง) ไม่ต้องสมัครเพิ่ม โกงยาก (แนะนำ) · B = ให้ทุกคน · C = ให้เฉพาะคนที่เข้าสู่ระบบสมาชิก (LINE / Google เปิดแล้ว) (ส่งฟรี ฿500 ทุกคน = เคาะแล้ว อยู่ในบันทึกคำตัดสิน)
78. หน้าตาที่ขึ้นเว็บแล้วแต่พี่ยังไม่ได้เคาะ (เก็บไว้ หรือบอกจุดที่อยากแก้): หน้าเข้าสู่ระบบ · ปุ่มเพิ่มลงตะกร้าแบบเร็ว · ข้อความแจ้งสลิปในกลุ่มไลน์จริง (เห็นเมื่อมีสลิปจริงใบแรก) · หน้าพนักงาน (พี่บอก 26/10 ว่ายังรก — คิวจัดใหม่แล้ว) · หน้าคืนเงิน B4 · (27/10) หัวเว็บจัดใหม่ไม่ให้เมนูตก 2 บรรทัด · การ์ดแนะนำในตะกร้า 8 ใบ ปัดได้บนมือถือ
79. แก้กฎกลางเรื่องรายงาน (พี่ขอ 27/10): ทุกข้อในรายงานและข้อความสถานะบอกสั้น ๆ ว่าทำเพื่ออะไร เพราะอะไร — พี่ตอบ "ได้" แล้ว Friday ใช้กับทุกโปรเจกต์

## งานที่พี่ต้องทำเอง

80. ให้สต็อกอัปเดตทุกชั่วโมง (พี่เลือกทาง 1 วันที่ 27/10): ตั้งคอมไม่ให้หลับตอนเสียบปลั๊ก (Windows → Power → "When plugged in … sleep" = Never) และไม่พับฝาโน้ตบุ๊กช่วง 08:00–00:00 — รูทีนสต็อกรันได้เฉพาะตอนคอมเปิด
81. ส่งรูปตัวเครื่อง Marbo 10K เทียบแท้ 1 รูป (ถ่ายเอง หรือรูปผู้ขายส่งที่ไม่มีโลโก้ SALTHUB) — ได้รูปแล้ว Friday ทำรูปการ์ดและเปิดหน้าให้เลย
77. (พี่ 24/10: ยังไม่ทำ) สำรองข้อมูลออเดอร์ไว้นอก Render: โค้ดพร้อมแล้ว เหลือพี่สมัครที่เก็บไฟล์ฟรี 1 ที่ (Backblaze B2 ไม่ต้องผูกบัตร หรือ Cloudflare R2 ต้องผูกบัตร) แล้ววางกุญแจใน Render — Friday พาทำทีละขั้นเมื่อพี่สะดวก (~20 นาที)

## คำถามถึงคลังสินค้า — พี่ก๊อปข้อความในกรอบส่งได้เลย (คลังตอบแล้ว Friday ลบออก)

```
สวัสดีครับ ร้าน OKami24 กำลังต่อหน้าเว็บกับระบบคลัง (Shipnity Max) ขอข้อมูลตามนี้ครับ
1. คู่มือ API ของ Shipnity Max: ที่อยู่ระบบ วิธีขอคีย์ ใครเป็นเจ้าของคีย์ และจำกัดการเรียกกี่ครั้ง
2. ขอคีย์สำหรับทดสอบ (อ่านอย่างเดียว) แยกจากคีย์ใช้งานจริง
3. ดึงรายการสินค้าพร้อมรหัสย่อย และจำนวนคงเหลือเป็นตัวเลขของแต่ละรหัสได้ไหม (ถ้ามีหลายคลังขอแยกคลัง · มีจำนวนที่จองไว้แยกไหม)
4. ถ้าของเข้า-ออก ระบบแจ้งมาที่เว็บเองได้ไหม หรือต้องให้เว็บดึงเป็นรอบ · ตัวเลขในระบบอัปเดตเร็วแค่ไหนหลังขาย/เติมของ
5. รหัสสินค้าเปลี่ยนได้ไหม (เคยเห็นรหัสเปลี่ยน) — มีรหัสประจำตัวที่ไม่เปลี่ยนเลยไหม
6. ส่งออเดอร์จากเว็บเข้าระบบ: ช่องค่าส่ง และช่องส่วนลด แยกจากยอดลูกค้าได้ไหม (ร้านจะส่งค่าส่งจริงทุกออเดอร์ ส่งฟรีเป็นส่วนลดที่ร้านจ่ายเอง)
7. ต้นทุนต่อรหัสสินค้าที่คลังเรียกเก็บจากร้าน ขอเป็นไฟล์หรือดึงจากระบบได้ไหม
ขอบคุณครับ
```
