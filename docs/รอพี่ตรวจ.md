# รอพี่ตรวจ

พี่ตอบเป็นเลขข้อได้เลย · มีเฉพาะเรื่องที่พี่ต้องตัดสิน ข้อละบรรทัด · ตอบแล้ว Friday ลบออก · งานรูปเสร็จแล้วขึ้นเว็บเลย พี่ดูบนเว็บเอง

## รอพี่ตัดสิน

58. ร้านขายหัวพอตรุ่นความจุเต็ม หรือรุ่น 2mL (แบบยุโรป)? ตอนนี้หน้าสินค้าเขียนไว้ทุกจุดว่า "(2mL ในเวอร์ชัน TPD)" — พี่ยืนยันเมื่อไหร่ Friday แก้ให้ตรง
63. รุ่นที่ลูกค้าพิมพ์ค้นแต่เว็บยังไม่มีหน้า — ร้านขายหรือหามาได้รุ่นไหนบ้าง (ตอบเป็นชื่อ · รุ่นที่พี่บอกว่าได้ Friday ส่งเข้ารอบลงสินค้า): Caliburn G3 (ตัวไม่ Pro) · Drag X · M Bar 18K · Marbo 25K · INFY 12K · JOIWAY 12K / 20K · Esko Bar 20K (ตัวไม่สวิตช์) · nexBAR Switch 15K · RELX Infinity / Diva / Sparta / Novo · ก้าน TEREA
64. ใช้คำว่า "ราคาส่ง" ในคำถามเรื่องซื้อยกลังได้ไหม (ไม่มีตัวเลข ยังให้ทักไลน์เหมือนเดิม) — ลูกค้าพิมพ์ "พอตราคาส่ง" "หัวพอตราคาส่ง" เยอะ (แนะนำ: ได้)
65. บทความใหม่ "พอตเปลี่ยนหัว รุ่นไหนดี" (ร่างเสร็จ รอลงหลัง 22/10) ต้องใช้คำ "พอตเปลี่ยนหัว" ในชื่อบทความ — ตอนนี้กฎคำให้ใช้ได้แค่ในบทความเทียบพอตใช้แล้วทิ้งกับพอตเปลี่ยนหัว · ให้ใช้ในบทความนี้ด้วยได้ไหม (แนะนำ: ได้ · ในเนื้อความยังเรียก "เครื่องระบบสวิตช์" เหมือนเดิม)
66. บทความ "เติมน้ำยาพอตยังไง" ขึ้นชื่อบนเว็บว่า "เติมพอตยังไง…" เพราะกฎเดิมไม่ให้คำว่า "น้ำยา" อยู่ในชื่อหน้า (ตอนนี้ร้านไม่มีน้ำยาขาย) · ยกเว้นให้หน้านี้ใช้ "เติมน้ำยาพอตยังไง" ตรงกับที่ลูกค้าพิมพ์ได้ไหม (แนะนำ: ได้ — เป็นวิธีใช้ ไม่ใช่หน้าขายน้ำยา)
67. บทความใหม่ "พอตของแท้ ดูยังไง" (ร่างเสร็จ รอลงหลัง 22/10) สอนลูกค้าเช็คของแท้ที่เว็บของแบรนด์เอง (UWELL · RELX · INFY · SALTHUB · Esko Bar · VOOPOO) · ถ้าลูกค้าเช็คแล้วไม่ผ่าน ร้านจะทำอะไรให้ — ตอนนี้นโยบายเคลมไม่มีข้อนี้ บทความจึงเขียนแค่ "ทักไลน์พร้อมแคปผลเช็คและคลิปแกะกล่องให้ร้านดู" ไม่สัญญาผล · ตอบได้ 3 แบบ: 1 คงแบบนี้ (แนะนำ ถ้ายังไม่อยากผูกมัด) · 2 เปลี่ยนของใหม่ให้เมื่อแจ้งภายใน 7 วันพร้อมคลิป (เพิ่มเข้านโยบายเคลม) · 3 แบบอื่น พี่บอกมา
60. ไฟล์ข้อมูลธุรกิจมีประโยคเทคนิคผิด 1 ประโยค (บอกว่าไฟล์หนึ่งถูกลบแล้ว แต่ไฟล์นั้นยังอยู่และทำหน้าที่อื่น) — ให้ Friday แก้ให้ตรงของจริงไหม (แนะนำ: แก้)

## งานที่พี่ต้องทำเอง

57. ถ้าสลิปที่โอนถูกถูกตัดสินผิดอีกครั้ง: พี่ลงทะเบียนบัญชีร้านที่ developer.easyslip.com จาก Chrome ของพี่ แล้วบอก Friday ทดสอบต่อ

## คำถามถึงคลังสินค้า — พี่ก๊อปข้อความในกรอบส่งได้เลย (คลังตอบแล้ว Friday ลบออก)

```
สวัสดีครับ ร้าน OKami24 กำลังต่อหน้าเว็บกับระบบคลัง (Shipnity Max) ขอข้อมูลตามนี้ครับ
1. คู่มือ API ของ Shipnity Max: ที่อยู่ระบบ วิธีขอคีย์ ใครเป็นเจ้าของคีย์ และจำกัดการเรียกกี่ครั้ง
2. ขอคีย์สำหรับทดสอบ (อ่านอย่างเดียว) แยกจากคีย์ใช้งานจริง
3. ดึงรายการสินค้าพร้อมรหัสย่อย และจำนวนคงเหลือเป็นตัวเลขของแต่ละรหัสได้ไหม (ถ้ามีหลายคลังขอแยกคลัง · มีจำนวนที่จองไว้แยกไหม)
4. ถ้าของเข้า-ออก ระบบแจ้งมาที่เว็บเองได้ไหม หรือต้องให้เว็บดึงเป็นรอบ · ตัวเลขในระบบอัปเดตเร็วแค่ไหนหลังขาย/เติมของ
5. รหัสสินค้าเปลี่ยนได้ไหม (เคยเห็นรหัสเปลี่ยน) — มีรหัสประจำตัวที่ไม่เปลี่ยนเลยไหม
6. ส่งออเดอร์จากเว็บเข้าระบบ: ช่องค่าส่ง และช่องส่วนลด แยกจากยอดลูกค้าได้ไหม (ร้านจะส่งค่าส่งจริงทุกออเดอร์ ส่งฟรีเป็นส่วนลดที่ร้านจ่ายเอง)
7. ต้นทุนต่อรหัสสินค้าที่คลังเรียกเก็บจากร้าน ขอเป็นไฟล์หรือดึงจากระบบได้ไหม
ขอบคุณครับ
```
