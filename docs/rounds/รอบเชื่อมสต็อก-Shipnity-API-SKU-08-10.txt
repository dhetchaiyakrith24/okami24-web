รอบ: เชื่อมสต็อก Shipnity API + SKU (เปิด 08/10 · คำสั่งจากแชท ไม่มีไฟล์แนบ — Friday คัดลอกคำสั่งในแชทลงไฟล์นี้)

คำสั่งเจ้าของ (ตามตัวอักษร):
อ่าน docs/HANDOFF.md §16 ก่อน · เปิดรอบใหม่ "เชื่อมสต็อก Shipnity API + SKU" — ก้อนแรกสำรวจอย่างเดียว ยังไม่แก้ไฟล์เว็บ:
(1) เทียบรหัสสินค้าบนเว็บทุกตัวเลือกกับ SKU ใน Shipnity → ตรงกี่ตัว ขาดกี่ตัว (2) อ่านเอกสาร API ที่ทีมสต็อกส่งมา (ถ้ายังไม่มี ให้ลิสต์สิ่งที่ต้องขอ)
(3) เสนอแผนตาม BUSINESS_SOURCE_OF_TRUTH §5–6 · ห้ามแตะ: รูปคอยล์ coil-1/72/94 (อีกแชทกำลังทำ) · ราคา · ห้าม merge งานขึ้นเว็บวันที่ 10/10

ลิงก์ Shipnity ที่เจ้าของส่งในแชท: https://app.shipnitymax.com/setting/account (เจ้าของล็อกอินเองในเบราว์เซอร์ของแอป)

【ห้ามแตะ】 รูปคอยล์ coil-1 / coil-72 / coil-94 · ราคา (ทุกไฟล์ราคา) · merge งานที่ขึ้นเว็บวันที่ 10/10
เกณฑ์ผ่านก้อนแรก: ตัวเลขตรง/ขาด ทุกตัวเลือกบนเว็บ · รายการสิ่งที่ต้องขอทีมสต็อก · แผนตาม BSOT §5–6 · ไม่มีไฟล์เว็บเปลี่ยน
