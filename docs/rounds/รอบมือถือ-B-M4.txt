【M4 ตัวกรอง — ตาม MOBILE_SPEC ทุกข้อ】
 - /products + หน้าหมวด + หน้าแบรนด์ บนมือถือ: ยุบ ค้นหา/แบรนด์/หน้าจอ/ขนาดพกพา/ระดับผู้ใช้ ทั้งหมดเป็นปุ่มเดียว "ตัวกรอง" (ใช้คำที่มีอยู่ใน dict ถ้ามี ห้ามคิดคำใหม่ — ถ้าไม่มี ให้ใช้คำสั้นที่ต้องผ่านเจ้าของก่อน)
 - เปิดหน้ามาต้องเห็นสินค้าชิ้นแรกในจอแรก (ใต้หัวเรื่อง) — ไม่มีแผงกรองขวาง
 - แถบเดียวกัน: ซ้าย "ตัวกรอง (n)" n = จำนวนที่เลือกอยู่ · ขวา "53 รายการ" + เรียงตาม (ที่มีอยู่แล้ว)
 - กดปุ่ม → แผ่นเลื่อนขึ้นจากล่าง (bottom sheet) ใส่ตัวกรองชุดเดิมทั้งหมด จัดกลุ่มเป็นหัวข้อพับได้ · ปุ่ม "ล้าง" + "ดูผล (n รายการ)" ติดล่างแผ่น · ปิดได้ด้วยปัดลง/แตะพื้นหลัง/ปุ่ม X · ล็อก scroll พื้นหลังตอนเปิด
 - เป้านิ้ว ≥44 · ไม่มี CLS · reduced-motion = ไม่มี animation
 - โครงสร้างแผ่นเลื่อน (bottom sheet) เขียนเป็น component กลาง — M5 (แผ่นตะกร้า) จะใช้ตัวเดียวกัน
