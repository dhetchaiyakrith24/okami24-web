0 · รอบนี้คืออะไร
======================================================================

เก็บของเล็กที่ค้างข้ามหลายรอบ ไม่ใช่ฟีเจอร์ใหม่
ทั้งสามข้อเป็นของที่ "เคยเห็นแล้วแต่ไม่ได้แก้เพราะไม่ใช่รอบของมัน"

ทิศทางของรอบนี้: **เก็บของค้างให้จบ ไม่เพิ่มของใหม่**
เจอทางที่ดีกว่าระหว่างทางให้ทำเลยไม่ต้องขอ แล้วเขียนมาในรายงาน
เจอของค้างอื่นที่อยู่ในทิศเดียวกันและอยู่ในไฟล์ที่แตะได้อยู่แล้ว ทำได้เลย
ของที่เป็นฟีเจอร์คนละเรื่อง = รอบใหม่ ไม่พ่วง

======================================================================
1 · สามข้อที่ต้องได้
======================================================================

ข้อ 1 — คำไทยหลุดบนหน้าภาษาอังกฤษ
   ตรวจแล้ว 22/09 โดย Cowork บนเว็บจริง: สลับเป็น English แล้วยังเห็น
   "สอบถามสินค้า" จากปุ่มไลน์ลอย (src/components/layout/LineContact.tsx)
   ต้องได้: สลับภาษาแล้วไม่เหลือคำไทยบนหน้า EN และ ZH
   คำที่ใช้แทนเลือกเอง ถ้าเว็บมีคำนี้ใช้อยู่แล้วที่อื่น ใช้ของเดิม ไม่ต้องถาม
   (กฎ 22/09: คำที่ใช้อยู่บนเว็บแล้วแต่ยังไม่มีคีย์ = ไม่ใช่คำใหม่)
   ถ้าต้องคิดคำที่ไม่เคยมีบนเว็บ = คำใหม่ ให้หยุดถาม

   จุดนี้เจอเพราะบังเอิญสลับภาษาดู ไม่ได้มาจากด่านไหน
   **อยากให้ดูด้วยว่ามีที่อื่นหลุดแบบเดียวกันอีกไหม** และถ้ามีวิธีทำให้
   ด่านจับได้เองในอนาคต เสนอมา (scan.js ตอนนี้ไล่แต่ HTML ที่ server ส่ง
   จับคำที่โผล่ตอนสลับภาษาฝั่ง client ไม่ได้)

ข้อ 2 — สี่หน้าที่ noindex แต่ยังอยู่ในแผนผังเว็บ
   ตรวจแล้ว 22/09 โดย Cowork: sitemap มี 103 URL
   ใน 103 นั้นมี 4 หน้าที่ติด noindex — /compare /finder /search /favorites
   ต้องได้: แผนผังกับ noindex พูดตรงกัน
   ตัวเลขหลังแก้ควรเป็น 99 แต่ให้ Code นับเองยืนยัน ไม่ต้องเชื่อเลขนี้
   รอบแชร์ลิงก์เคยทำเรื่องเดียวกันมาแล้ว (หมวดว่าง 105 → 103)
   ถ้ามีกลไกเดิมในโปรเจกต์ที่ใช้ซ้ำได้ ใช้ของเดิม อย่าสร้างกติกาที่สอง

ข้อ 3 — alias ค้นหา TFIT / INFY
   ยังไม่มีในชุด alias ที่ทำไว้รอบค้นหา
   ต้องได้: พิมพ์ชื่อสองแบรนด์นี้แบบที่คนไทยพิมพ์จริงแล้วเจอของ
   คำสะกดผิดเดาได้เต็มที่ — ผิดแล้วไม่เสียอะไร
   **alias ห้ามโผล่บนหน้าเว็บ** (กฎถาวร)

2 · ขอบเขต
======================================================================
