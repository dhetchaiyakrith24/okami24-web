0 · รอบนี้คืออะไร
======================================================================

**รอบตรวจ ไม่ใช่รอบแก้ — ห้ามแก้ไฟล์ใด ๆ ทั้งสิ้น ห้าม commit ห้าม push**
ผลลัพธ์เดียวของรอบนี้คือ "รายงาน" ไม่ใช่โค้ด

เจ้าของสั่งเอง: อยากให้ Code เดินดูเองแล้วบอกว่าตอนนี้ควรทำอะไรเพิ่ม
เพราะที่ผ่านมา Cowork เป็นคนคิดแล้วสั่ง Code ทำตาม เจ้าของกลัวว่าเรามัดมือชก
ไม่ปล่อยให้ Code ได้คิดเอง — รอบนี้คือการแก้ข้อนั้นโดยตรง

**Cowork มีรายการของตัวเองอยู่แล้ว แต่จงใจไม่บอก**
เพื่อให้สิ่งที่ Code เจอเป็นของ Code จริง ๆ ไม่ใช่เดาว่า Cowork อยากได้อะไร
พอ Code ส่งรายงานมา Cowork จะเอาสองรายการมาเทียบกันให้เจ้าของดู
ข้อที่ตรงกัน = มั่นใจได้ · ข้อที่ Code เจอคนเดียว = ของมีค่าที่สุดในรอบนี้

1 · ต้องตอบอะไร
======================================================================

คำถามเดียว: **"ตอนนี้ยังมีอะไรที่ทำได้เลยและควรทำ แต่เรายังไม่ได้ทำ"**

แบ่งคำตอบเป็น 3 กอง

กอง ก — ทำได้เลยตอนนี้
   ไม่ต้องรอใคร ไม่ต้องรอระบบอะไร เริ่มได้วันนี้
   เรียงตามผลที่จะได้ มากไปน้อย พร้อมเหตุผลว่าทำไมเรียงแบบนั้น
   แต่ละข้อบอกด้วยว่า: กระทบกี่หน้า · ชั้น A หรือ B · ประเมินว่ากี่ก้อน

กอง ข — ทำไม่ได้ตอนนี้ ต้องรออะไร (ทดไว้)
   บอกให้ชัดว่ารออะไรอยู่ และพอสิ่งนั้นมาแล้วจะทำอะไรได้บ้าง
   ที่รู้อยู่แล้วและต้องอยู่ในกองนี้: API คลัง (สิ้นเดือน) · ระบบตะกร้า
   ถ้าเจอข้ออื่นที่ติดรอเหมือนกัน ใส่เพิ่มได้

กอง ค — เคยคิดว่าควรทำ แต่ดูแล้วไม่ควรทำ
   พร้อมเหตุผล — กองนี้มีค่าพอ ๆ กับกอง ก
   การบอกว่า "อันนี้ไม่ต้องทำ" ช่วยประหยัดได้มากกว่าการเสนองานใหม่

2 · วิธีทำ
======================================================================

**Cowork จงใจไม่ให้เช็คลิสต์** ให้ Code เลือกวิธีดูเอง
แนวทางกว้าง ๆ ที่ทำได้ (ไม่ใช่คำสั่ง เลือกเองได้ ข้ามได้ เพิ่มได้)

- เดินเว็บจริงเหมือนลูกค้าเดิน ไม่ใช่ไล่ตรวจตามรายการ
  ลองตั้งต้นจาก "ถ้าเราเป็นคนที่เพิ่งอยากเลิกบุหรี่ ค้นเจอเว็บนี้ จะเจออะไร"
- ดูข้อมูลในรีโปเทียบกับที่ขึ้นจริงบนเว็บ
- ดูตัวเลขจริงใน docs/SEO_BASELINE.md และ SEO ที่ทำไปแล้ว 2 รอบ
- อะไรที่สคริปต์วัดได้ ให้วัด อย่าเดา

กติกาที่ต้องทำตาม
- **ทุกข้อต้องมีหลักฐาน**: URL หรือชื่อไฟล์ + สิ่งที่เห็นจริง
  ห้ามเขียนข้อเสนอลอย ๆ แบบ "ควรปรับปรุงเนื้อหาให้ดีขึ้น"
- **ห้ามเดาความรู้สึกลูกค้า** — เขียนสิ่งที่เห็น ไม่ใช่สิ่งที่คิดว่าลูกค้าจะรู้สึก
- **ห้ามเสนอเรื่องที่ตัดสินไปแล้ว** (รายการข้อ 3)
- **ห้ามแก้อะไรเลย** เจอของพังก็เขียนรายงาน ไม่ต้องแก้
- ภาพ: อ่านข้อความก่อนเสมอ ถ่ายเฉพาะข้อที่ต้องให้เห็นด้วยตา **ไม่เกิน 8 ภาพ**
- ถ้ารายงานออกมาสั้นเพราะไม่เจออะไร = ดี ไม่ต้องหาให้ครบจำนวน
  **ห้ามเสนองานเพื่อให้รายงานดูยาว**

3 · ตัดสินไปแล้ว ห้ามเสนอซ้ำ
======================================================================

- ตะกร้าปิดจนกว่าเจ้าของสั่งเปิดเอง
- งานรูปภาพทั้งหมด พักไว้ ห้ามเสนอ
- หน้าบริการ /warranty /shipping /how-to-order /privacy ไม่แตะจนเปิดตะกร้า
- กลุ่ม ก ห้ามแตะ: faq-copy.ts:61,63 · eliquid.disclaimer "สูบไอ" · /about ข้อความกฎหมาย · AgeGate
- เว็บเก่า okami24.net ปล่อยผ่าน ไม่ทำ 301
- ไม่ทำงานเทียบคู่แข่งออนไลน์
- ราคาแสดงจริงทุกตัว ห้ามเป็นช่วงราคา ห้ามให้ทัก
- สินค้าหมด = โชว์ต่อ ห้ามซ่อน
- โฟลเดอร์รูปต้นทาง salthub/joiway/uwell ห้ามแตะ

4 · งานค้างที่รู้อยู่แล้ว — ไม่ต้องเสนอซ้ำ แต่จัดกองให้หน่อย
======================================================================

รายการนี้ Cowork รู้อยู่แล้ว ไม่ต้องเสนอใหม่
แต่อยากให้ Code ช่วยบอกว่าแต่ละข้อควรอยู่กองไหน (ก / ข / ค) และควรทำก่อนหลังยังไง

- ด่าน "ไม่มีราคา = ซื้อไม่ได้" ใน catalog-resolver-contract-test.ts ใช้ slug ปลอม
- สคริปต์สำรอง DB หยุดตั้งแต่ 10/09 และสำรองอยู่ดิสก์เดียวกับต้นฉบับ
- dateModified ใน Article เป็นค่าตายตัว ควรดึงจาก git
- caliburn-g5 (3mL) ชนกับ coil-94 (2mL)
- Finder แนะนำแนวการสูบจาก attribute ที่ไม่มีแถวสเปกยืนยัน
- สินค้า 27 รุ่นยังไม่มีคลิป (ดึงอัตโนมัติได้แค่ 15 คลิปล่าสุดต่อช่อง)
- /brands/uwell บรรทัดสเปกใต้ชื่อรุ่นไม่สม่ำเสมอ
- คำใหม่ 18 คำ + ปม "แถว/บรรทัด" ใน THAI_STYLE_LOG §7 ยังไม่ล็อก
- docs/SEO_BASELINE.md บรรทัดวัน deploy ยังว่าง (ใส่ 2026-09-22)

5 · รูปแบบรายงาน
======================================================================

ส่งกลับเป็นข้อความในแชท ไม่ต้องสร้างไฟล์ใหม่ในรีโป
(ถ้าอยากเก็บไฟล์ ใช้ _incoming/ ได้ แต่ห้าม commit)

หัวข้อ 1 — ดูอะไรไปบ้าง (สั้น ๆ ว่าเดินหน้าไหน วัดอะไร)
หัวข้อ 2 — กอง ก ทำได้เลย (ตาราง: เรื่อง / หลักฐาน / กระทบกี่หน้า / ชั้น A-B / กี่ก้อน / ทำไมอยู่ลำดับนี้)
หัวข้อ 3 — กอง ข ติดรอ (เรื่อง / รออะไร / พอได้แล้วทำอะไรได้)
หัวข้อ 4 — กอง ค ไม่ควรทำ (เรื่อง / ทำไม)
หัวข้อ 5 — งานค้างข้อ 4 ข้างบน จัดกองแล้วเรียงลำดับ
หัวข้อ 6 — ถ้าให้ Code เลือกเอง 1 รอบถัดไป จะเลือกอะไร เพราะอะไร

**หัวข้อ 6 สำคัญที่สุด** — เจ้าของอยากรู้ว่าถ้าปล่อยให้ Code ตัดสินใจเอง
มันจะเลือกอะไร ตอบตามที่คิดจริง ถึงจะไม่ตรงกับที่ Cowork เคยพูดไว้ก็ตาม
ถ้าเห็นว่าลำดับงานที่วางไว้ตอนนี้ผิด บอกได้เลย

6 · ไม่มีจุดหยุด
======================================================================

รอบนี้ไม่มีจุดหยุดกลางทาง ตรวจจบแล้วส่งรายงานทีเดียว
ไม่ต้องขออนุญาตระหว่างทาง เพราะไม่ได้แก้อะไรอยู่แล้ว
