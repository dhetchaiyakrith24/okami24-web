ทำไมสำคัญ: เมื่อเปิดตะกร้าแล้ว เว็บจะรับออเดอร์และบันทึกลงฐานข้อมูลได้
แต่ถ้าไม่มีใครในทีมเห็นว่ามีออเดอร์เข้ามา ออเดอร์จะนอนเงียบจนลูกค้ารอเก้อ
นี่คือชิ้นสุดท้ายที่กั้นระหว่าง "เว็บทำงาน" กับ "ร้านขายได้จริง"
= ต้องเสร็จก่อนหรือพร้อมกับการเปิดตะกร้า ไม่ใช่หลังจากนั้น

【ขอบเขต — แคบไว้ก่อน ห้ามขยายเอง】
รายการออเดอร์ + เปลี่ยนสถานะ + แจ้งเตือน LINE เท่านั้น
ห้ามทำ: รายงานยอดขาย กราฟ จัดการสินค้า จัดการผู้ใช้ ส่งออก Excel
ถ้าคิดว่าจำเป็นจริง ให้เสนอ ไม่ใช่ทำเลย

【1 การเข้าใช้งาน】
 - เส้นทาง /admin
 - รหัสผ่านชุดเดียวสำหรับทีม อ่านจาก environment variable เท่านั้น
   ห้ามอยู่ในโค้ด ห้ามเข้า Git · ประกาศคีย์ใน render.yaml แบบ sync: false
   เจ้าของกรอกค่าเองในหน้า Environment (วิธีเดียวกับ QR)
 - เก็บรหัสเป็น hash ไม่ใช่ข้อความเปล่า
 - จำกัดจำนวนครั้งที่กรอกผิด กัน brute force
 - session cookie: httpOnly + secure + อายุ 7 วัน
 - ใส่ noindex ทั้งส่วน /admin ห้ามให้ Google เก็บเด็ดขาด
 - ถ้ายังไม่ล็อกอิน เข้า /admin อะไรก็ตาม ต้องเด้งไปหน้าล็อกอินเสมอ

【2 หน้ารายการออเดอร์】
 - ใหม่สุดอยู่บน
 - แต่ละแถวเห็น: เลขออเดอร์ · เวลา · ชื่อลูกค้า · เบอร์ · ยอดรวม · สถานะ
   · มีสลิปแล้วหรือยัง
 - กรองตามสถานะได้ · ค้นด้วยเลขออเดอร์หรือเบอร์โทรได้
 - ออกแบบให้ใช้บนมือถือได้จริง — แอดมินจะเปิดจากมือถือเป็นหลัก
 - ข้อความบนหน้าเป็นภาษาไทย · **ยึด docs/THAI_STYLE.md** (ตารางคำล็อก) เหมือนฝั่งลูกค้า

【3 หน้ารายละเอียดออเดอร์】
 - รายการสินค้าพร้อมกลิ่น/สีที่เลือก · จำนวน · ราคาต่อชิ้น · ยอดรวม
 - ชื่อ เบอร์ ที่อยู่จัดส่ง
 - รูปสลิปถ้าลูกค้าอัปโหลดไว้
 - ปุ่มเปลี่ยนสถานะ: ยืนยันการชำระเงิน / กำลังจัดส่ง / จัดส่งแล้ว / ยกเลิก
 - ทุกครั้งที่เปลี่ยนสถานะ ต้องบันทึกเวลาไว้ ดูย้อนหลังได้ว่าเปลี่ยนเมื่อไหร่
 - ปุ่มที่ย้อนไม่ได้ (ยกเลิก) ต้องมีถามยืนยันก่อน

【4 แจ้งเตือน LINE】
 - มีออเดอร์ใหม่ → ส่งเข้า LINE ทันที
   ข้อความ: เลขออเดอร์ · ยอดรวม · จำนวนชิ้น · ลิงก์เปิดหน้าออเดอร์นั้น
 - ห้ามใส่ที่อยู่หรือเบอร์ลูกค้าในข้อความ LINE (ข้อมูลส่วนบุคคล ให้ไปดูในหน้าแอดมิน)
 - ⚠️ ก่อนเขียนโค้ด ให้ researcher ตรวจก่อนว่า "ตอนนี้" ส่งข้อความเข้า LINE
   ด้วยวิธีไหนได้บ้าง และวิธีไหนยังใช้ได้จริง
   อย่าเดาจากความรู้เก่า บริการฝั่ง LINE เคยปิดตัวมาแล้ว
   ได้คำตอบแล้วรายงานมาว่าต้องขออะไรจากเจ้าของบ้าง (token / id)
   → เจ้าของจะให้ในแชทคุณ ไม่ผ่าน Cowork
 - ถ้ายังไม่ได้ตั้งค่า LINE ระบบต้องทำงานปกติ แค่ไม่ส่งแจ้งเตือน
   ห้ามพังทั้งระบบเพราะแจ้งเตือนส่งไม่ได้ · เขียน log บอกเหตุผล

【5 ห้ามแตะ】
 - หน้าฝั่งลูกค้าทั้งหมด ห้ามเปลี่ยนแม้แต่พิกเซลเดียว
 - ห้ามแตะ payment.ts · otp-mode.ts · paths.ts · sold-out.ts · การติดตั้ง QR
 - ห้ามแก้โครงตาราง orders ถ้าจำเป็นต้องเพิ่ม ให้เสนอก่อน

【6 ส่งมอบ】
 - ภาพหน้าจอ 390px ทุกหน้า (ล็อกอิน / รายการ / รายละเอียด)
 - ทดสอบจริง: สร้างออเดอร์ทดสอบ → เห็นในหน้าแอดมิน → กดเปลี่ยนสถานะ → สถานะเปลี่ยนจริง
   **⚠️ ข้อนี้ต้องเปิดตะกร้าก่อนถึงทำได้** ถ้ายังปิดอยู่ ให้หยุดถามเจ้าของก่อนเริ่มรอบ
 - ทดสอบว่าไม่ล็อกอินแล้วเข้าไม่ได้จริง
 - tsc + verify ทั้ง 2 ชุด + จำนวนสินค้าเท่าเดิม + checker อิสระ + designer
 - commit แยกชนิด → push → รายงาน 13.6
