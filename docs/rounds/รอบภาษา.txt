งานเดียวของรอบนี้: ตัวหนังสือบนเว็บ (Thai copy agent + ข้อ 30 + ข้อ 36)
ห้ามแตะเรื่องอื่น: รูป · SEO · มือถือ · ตะกร้า · แอดมิน

หลักการจากเจ้าของ (บังคับทุกข้อ):
 - ไม่แก้ของเก่าถ้าไม่ได้สั่ง ถ้าจำเป็นต้องแก้ ให้แจ้งก่อนพร้อมเหตุผล
 - หาจุดบอดของตัวเองแล้วรายงาน ไม่รอให้ถูกจับได้
 - รายงาน checker/designer ใช้รูปแบบ 5 ช่อง (ตรวจอะไร · commit ไหน · พบอะไร · หลักฐาน · ยังไม่ได้ตรวจอะไร)

【ขั้น 1】 สร้าง Thai copy agent ที่ .claude/agents/thai-copy.md ในโปรเจกต์
    ตามสเปกที่ Cowork ให้ไว้ (บทบาท / กฎห้ามละเมิด / อาการ AI เขียน / การทับศัพท์
    / วิธีทดสอบทุกประโยค / น้ำเสียง / ต้องดูแล docs/THAI_STYLE.md / รูปแบบรายงาน)
    ถ้ายังไม่มีสเปกนี้ในมือ ให้ขอจากเจ้าของก่อน ห้ามเขียนเอง

【ขั้น 2】 ให้ agent อ่านหน้าแรกเพียงหน้าเดียว ส่งตาราง ก่อน→หลัง ให้เจ้าของดู
    เจ้าของจะบอกว่าถูกโทนไหม — ถ้าไม่ถูก ปรับ agent ก่อน ห้ามไล่ทั้งเว็บด้วยโทนที่ผิด

【ขั้น 3】 โทนผ่านแล้ว → ไล่ทั้งเว็บ ส่งตารางรวมทีเดียว
    เรียงหน้าที่ลูกค้าเจอก่อนขึ้นก่อน: หน้าแรก → หมวดสินค้า → หน้าสินค้าขายดี
    → วิธีสั่งซื้อ → จัดส่ง → รับประกัน → ที่เหลือ
    ห้ามแก้ตัวเลข ราคา เงื่อนไข วันเวลา แม้จะคิดว่าผิด — ยกมาถามแทน
    การทับศัพท์: รวบรวมเป็นรายการเดียวให้เจ้าของเคาะครั้งเดียว บันทึกลง THAI_STYLE.md

【ขั้น 4】 เจ้าของเคาะแล้ว → ลงมือแก้ (ข้อ 30 ปลดล็อกแล้วเฉพาะรอบนี้)
    แก้เฉพาะแถวที่เคาะ ห้ามแก้เกิน · ทั้ง 3 ภาษาต้องความหมายตรงกัน
    designer ตรวจว่าข้อความใหม่ไม่ทำให้เลย์เอาต์แตก (ยาวขึ้น/สั้นลงจนพัง)

【ขั้น 5】 ข้อ 36 ช่องไฟภาษาไทยทั้งเว็บ — ทำเป็น commit แยก ไม่ปนกับข้อความ
    ภาพก่อน-หลัง 390px และ 1440px อย่างน้อย 3 หน้า
    ต้องเห็นชัดว่าดีขึ้นจริง ไม่ใช่แค่ต่าง

【ส่งมอบ】 tsc + verify 2 ชุด + 53/31 + checker + designer (รูปแบบ 5 ช่อง)
    commit แยก: agent / ข้อความ / CSS / docs → push → รายงาน 6 หัวข้อ
    ห้าม merge main ห้าม deploy เอง
