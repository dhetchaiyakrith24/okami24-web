【ก้อน 2】Render สร้างและขึ้นเว็บเองเมื่อ merge (autoDeploy) · ด่านตรวจข้อมูลสินค้าย้ายเข้าขั้นสร้างเว็บของ Render (ตก = ไม่ขึ้นเว็บ เว็บเดิมอยู่)
 · merge ที่ไม่แตะเว็บ (เอกสารล้วน) ไม่สร้างใหม่ (buildFilter) · GitHub Actions เหลือเฉพาะงานเบาที่ไม่สร้างเว็บ (หรือปิด)
 · self-merge-check / pre-checker-gate / 13.7 ปรับให้ใช้ผลตรวจบนเครื่องทดสอบแทนด่าน build ของ GitHub
 รู้ได้ยังไงว่าเสร็จ: merge PR ทดสอบ 1 ตัว → Render ขึ้นเว็บเอง (curl 200 + ของใหม่ขึ้น) · PR เอกสารล้วน → Render ไม่สร้าง ·
 GitHub Actions ไม่มีรอบ build ใหม่ · ลอง build ล้มโดยตั้งใจบน branch ทดสอบไม่ได้บน main — ใช้เอกสาร Render เป็นหลักฐาน
