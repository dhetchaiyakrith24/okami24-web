【🔴 เงื่อนไขหยุด — เขียนไว้ที่นี่เพราะ 2 รอบก่อน Code ข้ามคำสั่งหยุดในแชท】
 · **ก้อน 2 จบที่ "ส่งตาราง ก่อน→หลัง" เท่านั้น ห้าม commit ข้อความใด ๆ ที่ลูกค้าเห็น (title · description · og) ก่อนมีคำว่า "เคาะ" ในแชทจากเจ้าของหรือ Cowork** — ไม่มีคำนั้น = ยังไม่ได้เคาะ ไม่ว่าจะมั่นใจแค่ไหน
 · ทางเลือกที่ Cowork/เจ้าของสั่งเรียงลำดับไว้ ให้ทำตามลำดับ ถ้าทำไม่ได้ทุกทาง = หยุด รายงาน **ห้ามคิดทางที่ 4 เอง**
 · เจอ "ของที่ต้องยืนยันแต่ยืนยันไม่ได้" (ตัวเลข ค่าส่ง เงื่อนไข) = ตัดออก ไม่ใช่เดา (13.4 · THAI_STYLE)

【ห้ามแตะ】
 · หน้าบริการ /warranty /shipping /how-to-order /privacy — **ทั้งข้อความและ title/description** (คำตัดสินถาวร: ไม่แตะจนเปิดตะกร้า)
 · H1 ทุกหน้า (หน้าแรก "พอตไฟฟ้าของแท้ข้อมูลจริง" เคาะแล้ว 30.3ข) · กลุ่ม ก · AgeGate · โฟลเดอร์รูป · `src/components/` `src/app/**/page.tsx` ส่วน JSX (แตะได้เฉพาะ `metadata`/`generateMetadata` และ script JSON-LD)
 · ชื่อขนส่ง (EMS/ไปรษณีย์/Flash) ห้ามโผล่ทุกที่รวม JSON-LD (BSOT §10) · ที่อยู่ส่งคืนห้ามโผล่ (BSOT §12)
 · ห้ามเขียน "บุหรี่ไฟฟ้า" ถ้า THAI_STYLE ไม่มีคำนี้ในตารางคำล็อก — ใช้ "พอต" ตามที่เว็บใช้อยู่ · คำใหม่ = เจ้าของเคาะ
 · ห้ามคำอ้าง ถูกสุด/ดีที่สุด/ส่งฟรี(ถ้าไม่ตรงเงื่อนไข)/รับประกัน — ตาม thai-check ข้อ 5

【ก้อน 1】Organization + WebSite JSON-LD หน้าแรก — ชั้น A (ไม่มีข้อความที่ลูกค้าเห็น commit ได้เลยหลัง checker)
 ทำ: เพิ่มใน `src/lib/seo.ts` ฟังก์ชัน `organizationJsonLd()` + `websiteJsonLd()` แล้วฉีดที่หน้าแรก (แบบเดียวกับ breadcrumbJsonLd)
     Organization: `@id` = SITE_URL#organization · name "OKami24" · **alternateName ["OKM", "okm pod", "Okami vape", "okami24"]** · url · logo (ไฟล์ที่มีอยู่ใน public/ — อ่านชื่อจริง) · sameAs = LINE official URL + YouTube (เอาจาก `src/data/contact.ts` เท่านั้น ไม่มี = ไม่ใส่) · areaServed "TH"
     WebSite: name "OKami24" · alternateName "OKM" · url · inLanguage "th" · publisher → @id องค์กร · **ไม่ใส่ SearchAction** ถ้า /search ไม่รับ query param แบบที่ schema ต้องการ (เช็คก่อน)
     Product JSON-LD ทุกหน้า: `brand` คงเดิม · เพิ่ม `offers.seller` → @id องค์กร (ให้ Google ผูกสินค้ากับร้าน)
 agent: ไม่ต้อง · checker ก่อน commit
 รู้ได้ยังไงว่าเสร็จ: curl / มี 2 script ld+json ใหม่ · JSON parse ได้ · `alternateName` มี "OKM" · Rich Results Test ไม่มี error (Cowork ยิงให้ตอนปิดรอบ)

【ก้อน 3】ลงข้อความที่เคาะแล้ว + ราคาใน description สินค้าทุกหน้า — ชั้น A
 ทำ: ลง 9 หน้าตามตารางที่เคาะ (แก้ตรงที่ตาราง ห้ามแก้เพิ่ม) ·
     หน้าสินค้า: `generateMetadata` ต่อท้าย description ด้วย ` ราคา ฿{sellingPrice} ของแท้ สั่งทาง LINE @okm24` **อ่านราคาจาก catalog-index (แหล่งเดียวกับที่หน้าโชว์) ไม่ก๊อปเลข** · ถ้าเกิน 160 ตัวให้ตัดท้ายประโยคเดิมที่ขอบเขตประโยค ไม่ตัดกลางคำ · สินค้าไม่มีราคา (ไม่ควรมีแล้ว) = ไม่ต่อท้าย
     คำว่า "ราคา ฿…" นี้ต้องอยู่ในตารางก้อน 2 ให้เจ้าของเคาะด้วย 1 แถว (เป็นข้อความที่ลูกค้าเห็นใน Google)
 agent: thai-check ทุกก้อน · checker ก่อน commit
 รู้ได้ยังไงว่าเสร็จ: curl 3 หน้าสินค้าสุ่ม description มี "฿" ตรงกับราคาบนหน้า · scan.js 0 · i18n ผ่าน (en/zh description ไม่ต้องแตะรอบนี้ — ถ้า generateMetadata แชร์กัน ให้ต่อท้ายเฉพาะ locale th)

【ก้อน 4】JSON-LD ที่ยังขาด + offers ให้ครบช่องผู้ขาย — ชั้น A
 ทำ: BreadcrumbList ทุกหน้าที่ยังไม่มี (ใช้ breadcrumbJsonLd เดิม) · CollectionPage หน้าหมวด+แบรนด์ · FAQPage /faq (จาก faqs.ts) · Article หน้าคู่มือ (guides.ts) · ทั้งหมดอ่านจากข้อมูลที่มีอยู่ ไม่พิมพ์ข้อความใหม่
     offers ทุกสินค้าเพิ่ม (ข้อเท็จจริงจาก BSOT §10/§12 เท่านั้น):
       shippingDetails: OfferShippingDetails · shippingRate 60 THB · **freeShippingThreshold 500 THB ใส่ได้เฉพาะถ้า schema รองรับแบบไม่ต้องเขียนข้อความ** · deliveryTime transitTime 1–3 วัน · shippingDestination TH · **ห้ามใส่ชื่อขนส่ง**
       hasMerchantReturnPolicy: merchantReturnDays 7 · returnPolicyCategory MerchantReturnFiniteReturnWindow · returnMethod ReturnByMail · returnFees ReturnShippingFees · refundType ExchangeRefund (ไม่มีคืนเงิน) · applicableCountry TH
     ช่องไหน BSOT ไม่มีข้อเท็จจริง = ไม่ใส่ ไม่เดา

 รู้ได้ยังไงว่าเสร็จ: ทุก URL ใน sitemap มี ld+json ≥1 (สคริปต์นับ) · Rich Results Test หน้าสินค้า 1 หน้า: Product ผ่าน ไม่มี error · warning ผู้ขายหายจาก 2 → 0 (Cowork ดูใน GSC หลัง deploy)

【ตรวจ】
 · scope-auditor ตอนเปิดรอบ 1 ครั้ง — รอบนี้แตะ head ของทุกหน้าใน sitemap = ทุกหน้าคือขอบเขต
 · thai-check ทุกก้อนที่มีข้อความ · scan.js 0 จากทุกหน้า · raw-chars 0 · head/JSON-LD 0 อักขระล่องหน (thai-check ข้อ 3)
 · verify ครบชุดตาม round-close ขั้น 3 · count-storefront เท่าเดิม 53/53 (รอบนี้ไม่แตะ catalog)
 · **JSON ทุกก้อน parse ได้** — สคริปต์เล็กไล่ทุกหน้า: ld+json ทุกก้อน JSON.parse ผ่าน · Product มี offers.price ครบ 53 · Organization alternateName มี OKM
 · checker เช็คเพิ่ม: ไม่มีชื่อขนส่ง · ไม่มีที่อยู่ส่งคืน · ไม่มีคำอ้างต้องห้าม ในทุก description/JSON-LD ใหม่

【ส่งมอบ】
 · commit แยก: data (ก้อน 0) · seo-schema (ก้อน 1+4) · seo-copy (ก้อน 3+5 หลังเคาะ) · docs (ก้อน 6) · push หลัง checker ผ่าน · doc-keeper อัปเดต §16 ทุก push
 · ปิดรอบ = tag `seo-a-done` + push tag · รายงาน 4 บรรทัดตาม (ข)
 · **รอบนี้ deploy** — Cowork merge → deploy → ตรวจเว็บจริง → กด validate fix ใน GSC → ขอ index หน้าที่ยังไม่ถูกเก็บ

【ถ้าติด】
 · ไม่รู้ว่า THAI_STYLE อนุญาตคำไหน → ใช้คำที่มีบนเว็บอยู่แล้วเท่านั้น คำใหม่ใส่ในตารางก้อน 2 ให้เจ้าของเคาะ
