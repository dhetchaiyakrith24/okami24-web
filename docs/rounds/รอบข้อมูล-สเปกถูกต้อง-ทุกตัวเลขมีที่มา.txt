【ก้อน 1】กลไก: ทุกที่ที่โชว์สเปก ใช้เฉพาะแถวที่ยืนยันแล้ว — ชั้น B (แถวหายได้ = หน้าตาเปลี่ยน)
 ผลที่ต้องเป็นจริง:
 · ทุกจุดที่โชว์ตัวเลข/สเปกให้ลูกค้า (หน้าสินค้า · ProductHero · การ์ดในรายการ · การ์ดใต้บทความ · หน้าแบรนด์ · /compare · Finder · JSON-LD) อ่านเฉพาะแถว verified — แถวที่ไม่ใช่ verified ไม่โผล่เป็นข้อเท็จจริงที่ไหนเลย
 · แถวหายแล้วไม่มีช่องว่าง/ป้ายลอย/การ์ดที่แถวสเปกว่าง (HANDOFF §4 มี "6 cards with an empty spec row" เดิมอยู่แล้ว — ปิดในก้อนนี้ด้วย)
 · กันเกิดซ้ำ: มีด่านถาวรที่ฟ้องเมื่อ (ก) แถว verified ไม่มีลิงก์ที่มา หรือ (ข) คอมโพเนนต์ไหนอ่านสเปกโดยไม่เช็ค verified — กลไกด่าน Code เลือก · ทำลายให้แดงก่อนเชื่อ
 · PuffCount (dead code ตาม HANDOFF §4) — ถ้ายังไม่มีใครใช้ ลบได้ในก้อนนี้ commit แยก
 โจทย์ (ไม่ใช่คำสั่ง): ถ้าพบว่าการ "ไม่โชว์แถว unverified" ทำให้บางหน้าสเปกหายเยอะจนหน้าโหรง → อย่าฝืนซ่อน รายงานจำนวนหน้า/แถวก่อน แล้วเสนอทาง
 agent: scope-auditor (ครั้งเดียวตอนเปิดรอบ · รายการหน้าที่กระทบ = ด่านของ checker) · designer (390/1440 หน้าที่แถวหาย) · checker
 รู้ได้ยังไงว่าเสร็จ: นับทั้งเว็บก่อน/หลัง — จำนวนแถว unverified ที่ลูกค้าเห็น → 0 · การ์ดแถวว่าง → 0 · ด่านใหม่แดงเมื่อทำลาย เขียวเมื่อคืน

【ก้อน 2】SALTHUB: M Switch Pod · M Switch Kit · M Bar 9K — ชั้น A (ถ้าก้อน 1 ทำให้แถวหายเอง ก้อนนี้เหลือแก้ข้อมูล)

   โจทย์: ถ้าเจอแหล่งผู้ผลิตจริงที่เขียนความจุ M Switch Pod (โปสเตอร์/กล่อง/คู่มือบนเว็บ SALTHUB) → คงได้ พร้อมลิงก์และภาพหลักฐาน · ไม่เจอ = ตัด

 · ก้อนละ commit (หรือมากกว่า) แยกชนิดตาม 13.7 — ถอยได้ทีละก้อน · push หลัง checker ผ่าน · doc-keeper อัปเดต §16 ทุก push
 · **จุดหยุด = ก่อน merge:** แนบตารางก่อน→หลังของทุกอย่างที่ลูกค้าเห็น (แถวสเปก · ประโยค · ชื่อ · กลิ่น · ภาพ 390 ของก้อน 1/6) ไว้ที่ `_incoming/<รอบ>/owner-table.md` → Cowork อ่านเต็ม ส่วนที่เป็นการตัด/แก้ตามแหล่งผู้ผลิต Cowork เคาะได้ · ประโยคใหม่ที่ลูกค้าเห็น = เจ้าของเคาะ (13.4 #6) → Cowork merge/deploy + ตรวจเว็บจริง
 · ปิดรอบ = tag `data-facts-done` + push tag · รายงาน 4 บรรทัดตาม (ข) · แนบ: ตารางแถวที่สุ่มตรวจ (ก้อน 2) · รายการกลิ่นที่ไม่มีรูป (ส่งรอบ 11A) · ของที่ตัดทิ้งเพราะหาแหล่งไม่เจอ
 · ตอนปิดรอบบอกว่าคำสั่งนี้ตรงไหนบอกวิธีเกินจำเป็น (TEMPLATES (ค)-8)

【ถ้าติด】
 · เว็บผู้ผลิตเข้าไม่ได้/ข้อมูลขัดกันเองในเว็บผู้ผลิต → ไม่ตัดสินเอง จดเป็นคำถาม ก/ข ให้เจ้าของ ทำก้อนอื่นต่อ
 · การแก้ไหนต้องแตะ slug/URL/sitemap หรือ `<title>` ของ 7 หน้าเส้นฐาน → หยุดข้อนั้น ถาม
 · ก้อน 1 ทำให้สเปกหายเกินที่คาด (หน้าโหรง) → รายงานตัวเลขก่อน ไม่ฝืน
