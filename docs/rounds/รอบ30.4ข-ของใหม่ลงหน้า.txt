【รอบนี้แก้อะไร】
 30.4ก แก้ของเดิม · 30.4ค แปลของที่เหลือ · **30.4ข = เพิ่มของที่หน้ายังไม่มี** (คำนำหมวด · สเปกเด่นบนการ์ด · แถบความมั่นใจ) + เก็บของค้างเล็ก ๆ จากปิดรอบ
 ของใหม่ทุกชิ้น **ลูกค้าเห็นแบบใหม่ = เจ้าของต้องเห็นภาพก่อนขึ้นเว็บ** → ทุกก้อน: ทำบน build → ถ่าย 390+1440 → ส่งภาพให้เจ้าของเลือก → แล้วค่อย commit

━━━ หลักที่ใช้ทั้งรอบ (มีอยู่แล้ว ไม่ต้องถามซ้ำ) ━━━
 · ข้อความใหม่ทุกชิ้นต้องมี **3 ภาษา** (contract test บังคับ key ครบ en/zh) — ไทยจาก thai-copy · en/zh จาก writer · ความหมายเดียวกัน
 · ตัวเลขทุกตัวที่โผล่ในของใหม่ต้องมาจากแถวสเปก verified ของสินค้านั้น · ไม่มีตัวเลข = ไม่ใส่
 · ห้าม "ที่สุด" ที่ไม่มีตัวเลขครบทุกรุ่น · ห้าม health/price claim · ห้ามพูดถึงตะกร้า/สั่งซื้อ/จ่ายเงิน/ส่งฟรี (ตะกร้าปิด)
 · น้ำยา = 0 ชิ้น → ของใหม่ที่ผูกกับหมวดน้ำยา **ข้ามไปก่อน** (คำนำหมวด /e-liquid ไม่ทำ)
 · คำล็อก THAI_STYLE §3 ทั้งหมด · กาวล่องหน (thai-typography.ts) ครอบข้อความใหม่อัตโนมัติ — ข้อความใหม่ต้องผ่าน `<ThaiText>`/กลไกเดียวกัน
 · ห้ามเพิ่มรายการเข้า thai-typography.ts เอง (ต้องเจ้าของเคาะ) · ห้ามอักขระดิบในซอร์ส
 · หน้าบริการ (/warranty /shipping /how-to-order /privacy) ยังไม่แตะข้อความ (ข้อ 49 = รอบตะกร้า)

━━━ ลำดับก้อน ━━━
 **ก้อน 1 · เก็บของค้างจากปิดรอบ** (เล็ก · ทำก่อนเพื่อปิดบัญชี 30.4ค ให้สะอาด)
   1.1 หัวข้อ 3 จุดที่ 390 ยังจบด้วยคำโดด (เลือกพอตซิสเต็ม…ทิ้ง · MTL…ไหน · RDL…กลาง) → thai-copy เสนอแบบสั้น ≤15 อักษร/ท่อน 2 แบบ/หัวข้อ · title ตามถ้า H1=title
   1.2 หน้าแรก H2 ห่อบรรทัดที่ ~620px ทั้งที่แถวว่าง (max-width) → ปรับให้ใช้ความกว้างจริง
   1.3 /compare ที่ 390 คอลัมน์ 3 ถูกตัดขอบ ไม่มีตัวบอกว่าเลื่อนได้ → ใส่ตัวบอกเลื่อน (เงา/ลูกศร) ห้ามเปลี่ยนโครงตาราง
   1.4 หัวแถว /compare ที่ 1440 ~10px จิ๋ว → ขยายให้เท่า label สเปก (0.65rem) ตามที่ใช้ในก้อน 30.4ค
   → build → ถ่ายเฉพาะ 4 จุด → designer → commit fix-close · **ก้อนนี้ไม่ต้องรอเจ้าของเลือกภาพ** (แก้ของที่เคาะแล้ว)

 **ก้อน 2 · สเปกเด่น 1 บรรทัดบนการ์ดสินค้า** (การ์ดใน rail หน้าแรก + หน้าหมวด + สินค้าใกล้เคียง)
   · นับก่อน: การ์ดใช้ component เดียวกันกี่ที่ · สินค้าแต่ละตัวมีสเปก verified อะไรบ้าง
   · กติกาเลือกสเปกต่อประเภท (เสนอ · เจ้าของเคาะ): พอตซิสเต็ม/พอตคิท = แบตเตอรี่ + วัตต์สูงสุด · ใช้แล้วทิ้ง = จำนวนพัฟ · หัวพอต/คอยล์ = ค่าโอห์ม/ความจุ · HNB = แบตเตอรี่ · ไม่มีสเปก verified = ไม่แสดงบรรทัด (การ์ดสูงเท่าเดิม)
   · label ใช้คำล็อกเดิม (แบตเตอรี่ · วัตต์ · พัฟ · ค่าโอห์ม) · ฟอนต์/ขนาด = เดียวกับ SpecChip ที่มีอยู่ ห้ามสร้างสไตล์ใหม่
   · ส่งเจ้าของ: ตารางกติกา + ภาพการ์ด 2 แบบ (มี/ไม่มีบรรทัด) ที่ 390+1440 → เคาะ → commit feat-card-spec

 **ก้อน 3 · คำนำหมวด** (หน้าหมวด: พอตซิสเต็ม · พอตใช้แล้วทิ้ง · หัวพอต/คอยล์ · IQOS/HNB · **ข้ามน้ำยา**)
   · 2–3 ประโยคต่อหมวด ใต้ H1 · บอกว่าหมวดนี้คืออะไร เหมาะกับใคร ในร้านมีแบรนด์อะไร (เฉพาะที่มีจริง) · ไม่มีตัวเลขยอดขาย/จำนวนรุ่นที่จะเก่า
   · thai-copy เสนอ ≤2 แบบ/หมวด · writer แปล en/zh หลังเคาะไทย · คีย์เวิร์ดหมวดใช้ธรรมชาติ (รอบ SEO จะมาปรับ meta อีกที ไม่ต้องยัด)
   · ถ่าย 4 หน้า × 2 จอ → designer → เจ้าของเคาะข้อความ + ดูภาพ → commit feat-intro

 **ก้อน 4 · FAQ eyebrow ซ้ำ** (หน้าสินค้า: eyebrow "คำถามที่พบบ่อย" + H2 "คำถามที่พบบ่อยเกี่ยวกับอุปกรณ์นี้" ซ้ำกัน)
   · เสนอ 2 ทาง: ก) eyebrow สั้น "FAQ" (คงอังกฤษ = ชื่อส่วนสากล) · ข) eyebrow "ถาม-ตอบ" · H2 คงเดิม · ทำเหมือนกันทุกที่ที่มี eyebrow+H2 ซ้ำ (นับก่อน)
   · commit copy-eyebrow

 **ก้อน 5 · แถบความมั่นใจก่อน footer** (ตามที่ designer เสนอไว้ตอน 30.4ก)
   · 3–4 ข้อ: ของแท้ · ราคาตรง · บริการจริง (ตอบเอง ไม่ใช่บอท) · ข้อมูลเช็คกับเว็บทางการ — **เฉพาะที่เป็นจริงวันนี้** ห้าม "ส่งฟรี" "รับประกัน" "จ่ายผ่าน…" (ตะกร้าปิด · รับประกันดูหน้า /warranty เท่านั้น)
   · designer เสนอ 2 แบบ (แถวเดียว / การ์ด 4 ใบ) ถ่าย 390+1440 → เจ้าของเลือก → commit feat-trust
   · ไม่ใส่ไอคอนใหม่ที่ต้องมีไฟล์รูป (งานรูปพัก) — ใช้ไอคอนที่มีในระบบเท่านั้น

 **ก้อน 6 · ข้อเสนอ designer จาก 30.4ก ที่เหลือ** — Code ยกรายการจาก HANDOFF มาให้ก่อน (แต่ละข้อ: อะไร · หน้าไหน · ชั้น B แน่ · ประเมินเวลา) · เจ้าของเลือกทำ/ไม่ทำ · ทำเฉพาะที่เลือก
 **ปิดรอบ** — รัน `scripts/wordbreak-scan.js` ทุกหน้าที่แตะ (ไม่ต้องถ่ายทั้งเว็บ) + designer ดูเฉพาะจุดที่ธง → แก้ commit เดียว → รายงานปิดรอบ
