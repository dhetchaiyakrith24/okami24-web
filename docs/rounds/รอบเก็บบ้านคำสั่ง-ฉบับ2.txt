 9.1 **ไม่มี git tag เลย (0 tag)**
   ปัญหา: เจ้าของอ่าน commit hash ไม่ออก จะสั่งย้อนต้องบอกชื่อรอบได้
   ทำ: ติด annotated tag ย้อนหลังให้ commit ที่ปิดแต่ละรอบ
     **ชื่อ tag = อังกฤษล้วน ไม่มีช่องว่าง** (ไทยในชื่อ tag เสี่ยงเพี้ยนบน Windows/บางเครื่องมือ)
     **ข้อความใน tag = ไทย** ที่เจ้าของอ่านออก · RECOVERY.md มีตารางแปลชื่อ
     เช่น `lang-done` → "จบรอบภาษา" (b273929) · `r30-4b-done` → "จบรอบ 30.4ข" (998694e) ·
     `pre-housekeeping` → "ก่อนรอบเก็บบ้าน" (commit ก่อนเริ่มรอบนี้)
   แล้วเขียนเป็นกติกาถาวรใน 13.7: **ปิดรอบทุกครั้ง = ติด tag ก่อน push** · push tag ด้วย
   (tag เป็น metadata ไม่แตะโค้ด — ไม่ขัดกับ "ห้ามแตะ src/")

 9.2 **สคริปต์สำรอง DB หยุดทำงานตั้งแต่ 2026-09-10 18:32 (7 วัน)**
   [ตรวจแล้วจริง] `OKami24-backups/latest.json` + `backup.log` บรรทัดสุดท้าย = 10/09 18:32
   ไฟล์ล่าสุด okami24-2026-09-10T18-32-36.db · รวม 30 ไฟล์ · integrity=ok ทุกไฟล์ · `envFiles: []`
   **ยังไม่เสียหายตอนนี้** เพราะตะกร้าปิด ออเดอร์เข้าทาง LINE ไม่เข้า DB
   และ `.data/okami24.db` ในเครื่องไม่ได้ถูกแก้มาตั้งแต่ 06/09
   **แต่วันที่เปิดตะกร้า อันนี้กลายเป็นเรื่องใหญ่ทันที**
   ทำ: อ่าน `docs/BACKUP.md` (10 KB · 05/09) ก่อน — น่าจะบอกว่าสคริปต์ชื่ออะไร รันด้วยอะไร
     (scheduled task / npm script / รันมือ) แล้วหาว่าทำไมหยุด 10/09
     → รายงานสาเหตุ **ห้ามแก้ scheduled task ของเครื่องเจ้าของเอง ให้บอกเจ้าของกดเอง**
   ตรวจเพิ่ม: สคริปต์นี้สำรอง DB ในเครื่อง (dev) — **ยังไม่มีใครยืนยันว่าสำรอง DB ตัวจริงบน Render ด้วย**
     → ให้ตรวจ render.yaml ว่า disk ของ production อยู่ตรงไหน มีแผนสำรองไหม แล้วรายงาน
