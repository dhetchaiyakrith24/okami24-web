ต่อยอดรอบ 7: ให้ข้อความที่ลูกค้าเห็นรองรับคีย์หลักด้วย ไม่ใช่แค่ head

ต้องได้อะไร (คำตัดสินเจ้าของ 23/09)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1) หน้าแรก: เด่นสุดคือ "Pod system" · รองลงมาคือ "บุหรี่ไฟฟ้า" (จะอยู่ส่วนไหนของหน้าก็ได้)
   เจ้าของให้เขียนใหม่/ออกแบบใหม่ได้ = ชั้น B · designer ต้องผ่าน · เจ้าของชอบความสวยมาก่อนความเร็ว
2) หน้าแรกลิงก์ไปสินค้า ProductMaster 16 ตัวที่ยังไม่มีลิงก์จากหน้าแรก (คันโยกเดียวที่ข้อมูลรอบ 7 แยกเรื่อง Google ไม่เก็บได้)
   ทำรวมกับข้อ 1 ได้ ให้หน้าแรกไม่รก — วิธีจัดวาง Code/designer เลือก
3) Marbo + M Bar ให้ติดทั้งสองคำ — ใช้แผนที่ Code เสนอไว้ (title แบรนด์ · ประโยคในเนื้อ · FAQ "Marbo กับ M Bar ต่างกันไหม")
   ประโยคที่บอกว่าสองชื่อนี้คืออะไรกัน ต้องสืบกลับแหล่งได้ ถ้าสืบไม่ได้ ให้เขียนแค่ที่พิสูจน์ได้
   หน้าที่อยู่ในเส้นฐาน 05/10 ยังพักไว้ตามเดิม
4) คู่มือ pod system: หัวข้อ "Pod system คืออะไร" + "ยี่ห้อไหนดี" แบบไม่จัดอันดับ · ภาษาไทยอย่างเดียว
5) /e-liquid: หัวข้อ salt nic กับ freebase + ชวนทักไลน์ · บอกชัดว่ายังไม่มีขายหน้าร้าน
   ใช้คำ "น้ำยา" ใน head หน้านี้ได้ (ยกเว้นจากกฎ 4b เฉพาะหน้านี้)
6) FAQ ราคาส่ง/ซื้อยกลัง = "ติดต่อหลังไมค์ทางไลน์" ไม่มีตัวเลข ไม่พูดส่วนลด · "ที่ร้านตอนนี้มี" → "ที่ร้านมี" (RINCOE · DOTMOD)
7) นับคนกดปุ่มไลน์: นับเองในเว็บ ไม่มีคุกกี้ ไม่ส่งข้อมูลออกนอก · Cowork ต้องเปิดดูตัวเลขได้เอง (บอกมาว่าดูที่ไหน)
8) ตัววัดผู้เข้าชม Cloudflare: ทำงานแล้ว ไม่ต้องทำ (Cowork ตรวจซ้ำ 23/09: โหลดหน้าจริงมีสคริปต์ beacon ·
   Cloudflare นับได้ 26 เพจวิว/5 คนใน 24 ชม.) — ที่เคยบอกว่า "ไม่ขึ้น" เพราะ Cowork ตรวจด้วย fetch ซึ่ง Cloudflare ไม่ฉีดให้
   ห้ามใส่ snippet ซ้ำ จะนับซ้อน
9) «ถูกแบบ» ในชื่อคู่มือ — ผูกคำตามที่เสนอ

ตอบเจ้าของก่อนเริ่ม (สั้น ≤10 บรรทัด · ตอบพร้อมแผนตอนเปิดรอบ แล้วเดินงานต่อได้เลย)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
เจ้าของอยากเข้าใจเรื่อง "4-5-6" (สิ่งที่ Code เห็นเองระหว่างทำ นอกเหนือจากที่สั่ง):
1. ตอนนี้ระบบทำงานของ Code เดินยังไง — สรุปให้คนไม่อ่านโค้ดเข้าใจ
2. ระหว่างทำ ถ้าเกิดไอเดีย / เห็นหัวข้ออื่นที่ควรทำ / อยากต่อยอดตรงนั้นเลย — Code ตัดสินยังไงว่า
   "ทำเลย" หรือ "เสนอก่อน" และรายงานกลับมาหน้าตายังไง (ยกตัวอย่างสั้น ๆ)
3. ตัวอย่างจริง: ตอนนี้เราทำ SEO อยู่ — Code เห็นส่วนอื่น (นอก SEO ก็ได้) ที่ควรให้ความสำคัญพอ ๆ กันไหม
   มีอะไรที่เพิ่งคิดได้ระหว่างรอบ 7 แล้วอยากทำต่อไหม
4. สิ่งที่ตอบข้อ 2–3 ใช่ "4-5-6" จริงไหม หรือเป็นแค่งานค้าง/ความชอบ — แยกให้เห็น
ห้ามเริ่มทำหัวข้อใหม่จากข้อ 3 เอง — เสนอมาเป็นรายการ เจ้าของเลือก
