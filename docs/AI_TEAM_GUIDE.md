## 2\. ทีมมีใครบ้าง

|ตัวไหน|หน้าที่|Model|ทำไมต้องตัวนี้|
|-|-|-|-|
|**checker**|ตรวจงานก่อนส่งถึงคุณ|**Sonnet**|ถูกเรียกบ่อยที่สุด ต้องเร็วและถูก งานไล่เทียบไม่ต้องคิดลึก|
|**planner**|วางแผนงานใหญ่|**Fable**|ต้องมองภาพรวมและตัดสินใจเชิงโครงสร้าง — ใช้นาน ๆ ครั้ง คุ้มที่จะใช้ตัวแพง|
|**designer**|คุมทิศทางงานภาพ|**Fable**|รสนิยมและการตัดสินใจเชิงความรู้สึก ตัวเล็กทำไม่ได้ดี|
|**researcher**|หาข้อมูลจริง|**Sonnet**|อ่านเยอะ สรุปเยอะ แต่ไม่ต้องคิดซับซ้อน — Opus จะแพงเกินจำเป็น|
|**writer**|เขียนภาษาไทย|**Opus**|น้ำเสียงและจังหวะภาษาเป็นเรื่องละเอียด ตัวเล็กจะออกมาเหมือน AI เขียน|

### เรื่อง Model — พูดตรง ๆ

* **Opus** = ฉลาดที่สุด ช้าที่สุด แพงที่สุด ใช้กับงานที่ต้องคิด
* **Sonnet** = สมดุล เร็ว ถูกกว่ามาก ใช้กับงานที่มีขั้นตอนชัดอยู่แล้ว
* **Haiku** = เร็วและถูกที่สุด เหมาะกับงานง่ายมาก ๆ — ทีมนี้ยังไม่มีตัวไหนควรใช้
* **Fable** = รุ่นสูงสุด ใช้กับ planner/designer

**ถ้าอยากประหยัด:** เปลี่ยน `writer` เป็น Sonnet ก่อนได้ แล้วค่อยดูว่างานเขียนตกลงไหม ส่วน `designer` กับ `planner` ไม่แนะนำให้ลด

วิธีเปลี่ยน: เปิดไฟล์นั้นด้วย Notepad แล้วแก้บรรทัด `model: opus` เป็น `model: sonnet`

## 3\. สั่งงานยังไง

### แบบที่ 1 — ปล่อยให้เรียกเอง (ค่าเริ่มต้น)

ไม่ต้องทำอะไร ใน `CLAUDE.md` เขียนไว้แล้วว่าเมื่อไหร่ต้องเรียกใคร สั่งงานปกติได้เลย

### แบบที่ 2 — สั่งตรง ๆ เมื่ออยากใช้ตัวไหนเป็นพิเศษ

พิมพ์ชื่อมันไปเลย:

```

ส่งให้ checker ตรวจอีกรอบ
ให้ researcher หาราคาตลาดมาให้หน่อย
```

### แบบที่ 3 — ใช้หลายตัวต่อกัน

```
ให้ planner วางแผนก่อน แล้วค่อยเริ่มทำ พอเสร็จให้ checker ตรวจ
```

## 5\. ข้อจำกัดที่ต้องรู้ก่อนใช้

**1. ผู้ช่วยไม่เห็นบทสนทนาของเรา**
มันเห็นแค่สิ่งที่ส่งให้ตอนเรียกใช้ ถ้าผมส่ง context ไม่ครบ มันก็ตรวจผิด — ถ้าเห็นผลตรวจแปลก ๆ มักจะเป็นเพราะเรื่องนี้

**2. เรียกผู้ช่วยแล้วช้าลง**
แต่ละครั้งใช้เวลาเพิ่ม 10-60 วินาที ยอมช้าเพื่อไม่ต้องแก้ซ้ำ 3 รอบ คุ้มกว่า

**3. Fable และ Opus แพงกว่า Sonnet หลายเท่า**
`planner` `designer` เป็น Fable, `writer` เป็น Opus ใช้บ่อยจะเปลืองโควตา — ถ้าเริ่มรู้สึกว่าหมดเร็ว บอกผม เดี๋ยวปรับให้

**4. ไฟล์เหล่านี้ใช้ได้เฉพาะ Claude Code**
ในแชทหรือ Cowork ใช้ไม่ได้ ที่นั่นใช้ความจำถาวรแทน
