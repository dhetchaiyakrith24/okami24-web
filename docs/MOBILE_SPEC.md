สเปกงานมือถือ OKami24 (M1–M5)
═══════════════════════════════════════
กฎเหล็กของทั้งชุด: ทุกข้อคือ MOBILE ONLY
แตะ desktop ไม่ได้แม้แต่พิกเซลเดียว ต้องพิสูจน์ด้วยภาพ 1440px ก่อน-หลังว่าไม่ขยับ
แบ่งด้วย CSS breakpoint เท่านั้น ห้ามเดาจาก user agent
ลำดับที่แนะนำ: M2 → M3 → M4 → M5 → M1

─── [M1] หน้าแรก — motion เวอร์ชันมือถือ ───
คอม: intro animation คงไว้เหมือนเดิมทุกอย่าง ห้ามแตะ
มือถือ:
 - ห้ามมีจอดำคั่น ห้ามมีปุ่ม SKIP INTRO
   เปิดมาต้องเห็นรูปสินค้า + หัวเรื่อง + ปุ่ม ตั้งแต่เฟรมแรก
   motion เล่นทับเนื้อหาที่เห็นแล้ว ไม่ใช่ฉากกั้นก่อนเข้า
 - ยาวรวมไม่เกิน 0.8 วินาที เล่นรอบเดียว ไม่วนซ้ำ ไม่เล่นซ้ำตอนกดย้อนกลับ
 - ลำดับ: รูปลอยเข้า + แสงวิ่งผ่านตัวเครื่อง 1 ครั้ง
        → หัวเรื่องไทยไล่ขึ้นทีละบรรทัด → ปุ่ม CTA ท้ายสุด
 - ชื่อแบรนด์ UWELL / VOOPOO / SALTHUB ที่เดิมกินเต็มจอทีละอัน
   → ย้ายลงเป็นแถบโลโก้เลื่อนช้าใต้ hero

─── [M2] หน้าสินค้า — ย้ายแถบสี/กลิ่น + ปัดเปลี่ยน ───
ปัญหาปัจจุบัน (Cowork วัดบนจอ 390px แล้ว):
ลำดับคือ ชื่อ → รูป → ราคา → แถบกลิ่น → ปุ่มซื้อ
แถบกลิ่นอยู่ต่ำจนต้องปัดลง แล้วปัดกลับขึ้นไปดูรูป เด้งไปเด้งมา

 2.1 ย้ายแถบสี/กลิ่นขึ้นมาไว้ "ใต้รูปทันที" — ก่อนราคา
 2.2 ปัดซ้าย-ขวาที่รูป = เปลี่ยนสี/กลิ่น
     (อ้างอิงพฤติกรรมแกลเลอรีสินค้าบนมือถือของ apple.com)
     - ปัด = เลือกจริง ไม่ใช่แค่พรีวิว ของที่เลือกอยู่คือของที่จะลงตะกร้า
     - แถบชิปด้านล่างไฮไลต์ตามทันที และเลื่อนตัวเองให้ชิปที่เลือกอยู่ในสายตาเสมอ
     - จิ้มชิปก็ยังต้องได้ ทั้งสองทางต้อง sync กัน
     - มีจุดบอกตำแหน่ง (dots) ว่ามีทั้งหมดกี่ตัว อยู่ตัวที่เท่าไหร่
     - ราคา/สถานะของหมด อัปเดตตามตัวที่เลือก
 2.3 สินค้าที่ยังไม่มีรูปแยกรายกลิ่น: ปัดได้เหมือนกัน รูปคงเดิม เปลี่ยนแค่ชื่อกลิ่น
     พอมีรูปจริงเมื่อไหร่ ระบบต้องทำงานเต็มทันทีโดยไม่ต้องแก้โค้ดอีก
 2.4 ปุ่ม "เพิ่มลงตะกร้า" → ลอยติดขอบจอล่างตลอด (sticky)
     พร้อมราคาและชื่อตัวที่เลือกอยู่ · ต้องไม่บังเนื้อหาท้ายหน้า เผื่อ padding ล่างให้พอ

─── [M3] ขนาดรูป ───
วัดของจริง: การ์ดแคตตาล็อกสูง ~420px บนจอกว้าง 390px = 1 ชิ้นเต็มจอ
หน้าสินค้ากรอบรูปสูง ~600px แต่ตัวสินค้ากินแค่ ~40% ที่เหลือเป็นพื้นดำเปล่า

 3.1 แคตตาล็อก + หน้าหมวดหมู่บนมือถือ → 2 ชิ้นต่อแถว
 3.2 หน้าสินค้า → ลดพื้นที่ว่างรอบตัวสินค้า ให้สินค้ากินพื้นที่กรอบมากขึ้นชัดเจน
     เป้า: เห็นรูป + ชื่อ + ราคา + แถบกลิ่น ในหน้าจอเดียวโดยแทบไม่ต้องไถ
 3.3 ห้ามลดความละเอียดไฟล์ ห้ามแตะ WebP 82 — ลดแค่ "ขนาดที่แสดง"
 3.4 ตัวเลขที่แน่นอนให้คุณกับ designer ตัดสิน แต่ต้องส่งภาพให้เจ้าของดูก่อนถือว่าจบ
 3.5 ชื่อสินค้าบนการ์ดตัดที่ 2 บรรทัด ใส่ … ท้าย เพื่อให้การ์ดสูงเท่ากันทุกใบ
 3.6 [เพิ่ม 2026-09-16 · รอบ 30.4ข ก้อน 2 · เจ้าของเคาะ ข] การ์ดมือถือมีบรรทัดสเปกเด่น 1 บรรทัด
     (0.65rem · dim · truncate) ระหว่างชื่อกับราคา → ลำดับใหม่ รูป → แบรนด์ → ชื่อ → สเปก → ราคา
     (ราคาปิดท้าย · การ์ดไม่มีราคาเว้นช่องล่างสุด) · ตัวเลขจากแถวสเปก verified เท่านั้น ไม่มี = ว่างสูงเท่าเดิม
     · การ์ดสูงขึ้น 18px ทุกใบเท่ากัน (312 → 330 ที่ 390px) · กติกาเลือกสเปก: THAI_STYLE_LOG §7 "รอบ 30.4ข ก้อน 2"

─── [M4] ตัวกรองขวางทางบนมือถือ ───
เปิด /products บนมือถือ เจอช่องค้นหา + checkbox แบรนด์ 11 อัน + หน้าจอ
+ ขนาดพกพา + ระดับผู้ใช้ กางเต็มขวางอยู่ "ก่อน" สินค้าชิ้นแรก
 → ยุบทั้งหมดเป็นปุ่ม "ตัวกรอง" ปุ่มเดียว กดแล้วเปิดเป็นแผ่นเลื่อนขึ้นมา
 → เปิดหน้ามาต้องเห็นสินค้าทันที
 → ถ้ามีตัวกรองที่เลือกอยู่ ให้ขึ้นตัวเลขบนปุ่ม เช่น "ตัวกรอง (2)"
 → แสดงจำนวนสินค้าที่เจอไว้อีกฝั่งของแถบเดียวกัน

─── [M5] ตะกร้า — แบบ Shopee ───
⚠️ ข้อนี้เจ้าของแก้คำสั่งเดิม: เอาแบบ Shopee (ฉบับแรกเขียนว่าห้าม ให้ยึดฉบับนี้)

 5.1 กด "เพิ่มลงตะกร้า" → เปิดแผ่นเลื่อนขึ้นจากขอบล่าง (bottom sheet)
     ไม่ใช่ลงตะกร้าทันที · ในแผ่นต้องมี:
       - รูปตัวที่เลือกอยู่ + ชื่อสินค้า + ราคา + สถานะสต็อก
       - ตารางกลิ่น/สีให้เลือก ตัวที่หมดขึ้นเทาและกดไม่ได้ (กฎเดิม คงไว้)
       - ตัวปรับจำนวน − 1 +
       - ปุ่มยืนยัน "เพิ่มลงตะกร้า" อยู่ในแผ่น
       - ปิดแผ่นได้ด้วยการปัดลงหรือแตะพื้นหลัง
 5.2 ต้องสอดคล้องกับ M2 ห้ามให้ลูกค้ารู้สึกว่าเลือกซ้ำสองรอบ
     - ถ้าเลือกกลิ่นที่หน้าสินค้าไว้แล้ว แผ่นต้องเปิดมาโดยเลือกตัวนั้นไว้ให้แล้ว
       ลูกค้าแค่กดยืนยัน = จบใน 1 แตะ · ห้ามเปิดมาว่างเปล่า
     - ถ้าเปลี่ยนใจในแผ่น พอปิดแผ่น หน้าสินค้าด้านหลังต้องเปลี่ยนตามด้วย
       รูป ชิป ราคา ต้องตรงกันทั้งหมด ห้ามหลุด sync
 5.3 ใช้แผ่นเดียวกันกับการ์ดสินค้าในแคตตาล็อกด้วย
     ใส่ปุ่มตะกร้าเล็ก ๆ ที่การ์ด กดแล้วเปิดแผ่นเดียวกัน
     ลูกค้าซื้อได้โดยไม่ต้องเข้าหน้าสินค้า
     (อ้างอิง levi.co.za บนมือถือ: 2 ชิ้นต่อแถว · การ์ดมีแค่ รูป/ชื่อ 2 บรรทัด/ราคา
      /ปุ่มซื้อเต็มความกว้าง · ปุ่มซื้อคือของที่เด่นที่สุดในการ์ด)
 5.4 หลังกดยืนยัน: แผ่นปิด แล้วเล่น feedback เบา ๆ ไม่อลังการ
     รูปสินค้าตัวเล็กลอยไปที่ไอคอนตะกร้ามุมบน → ไอคอนเด้งเบา → ตัวเลขเพิ่ม
     รวมไม่เกิน 0.4 วินาที
     ตามด้วยแถบบาง ๆ "เพิ่มลงตะกร้าแล้ว" + ลิงก์ "ดูตะกร้า" หายเองใน 3 วินาที
     ห้ามบังปุ่มซื้อ ห้ามขวางการซื้อชิ้นถัดไป
 5.5 สินค้าที่ไม่มีตัวเลือกเลย → ไม่ต้องเปิดแผ่น ลงตะกร้าทันที

─── ข้อบังคับทางเทคนิคของทั้งชุด ───
 - ห้ามเกิด layout shift (CLS) จองพื้นที่รูปไว้ล่วงหน้าทุกจุด
 - รูป hero คือ LCP โหลดแบบ priority ห้ามให้ motion หน่วง
 - รองรับ prefers-reduced-motion: ปิด animation ทั้งหมด แสดงผลนิ่ง
 - ทุก target ที่นิ้วกด ขนาดไม่ต่ำกว่า 44x44px
 - การปัดต้องไม่แย่งการเลื่อนหน้าจอแนวตั้ง
 - ต้องทำงานบน Safari iOS ด้วย ไม่ใช่แค่ Chrome
