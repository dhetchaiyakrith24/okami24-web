Owner 10/11 ~01:35: "เริ่มคีย์ออเดอร์ลงเว็บ และตรวจสอบให้ดีว่าจะเจอช่องโหว่อะไรบ้าง". Trial period: cart closed, warehouse
not shipping, admins key LINE orders on `/staff/line-order` (#1331, migration 0026), warehouse switch OFF.

Method: walk the admin's day (chat → key → slip → warehouse → ship → after-sale) against the code on
`backoffice-line-orders` + main at 10/11. Every row says what happens TODAY, the fix, and who decides. "Code" = read
in the code; "unknown" = not proven on a real order or not documented by Shipnity — never guessed.

Ranked by money and customer harm (1 = worst).
