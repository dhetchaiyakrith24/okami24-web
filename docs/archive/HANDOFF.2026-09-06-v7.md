## 8. ความเสี่ยงและจุดต้องระวัง (มากไปน้อย)

1. **ถ้าเปิดขายวันนี้ ลูกค้ายังซื้อครบวงจรไม่ได้** — OTP ไม่ส่ง SMS จริง และทีมไม่มีหน้าจอดูออเดอร์ (ทดไว้ทั้งคู่ตามคำสั่งเจ้าของ) · เรื่องรับเงินพร้อมแล้ว
2. **ข้อมูลบัญชีอ่านจากรูป ยังไม่มีคนยืนยัน** — ถ้าผมอ่านชื่อผิดตัวเดียว ลูกค้าโอนไม่ตรงชื่อ → ต้องยืนยันก่อนเปิดขาย
3. **เลขบัญชีจริงอยู่ในโค้ด** (`src/data/payment.ts`) และ BSOT — repo private (ตรวจแล้ว) แต่ถ้าเปลี่ยนเป็น public จะหลุด · ชื่อบัญชีเป็นชื่อบุคคล
4. **หน้า `/warranty` ยังไม่ผ่าน designer** — checker ตรวจเนื้อหา/เส้นทางผ่านแล้ว แต่ไม่มีใครตรวจเรื่องเลย์เอาต์รอบสุดท้าย
5. **ไฟล์ QR อยู่นอก git และนอกระบบสำรองอัตโนมัติ** — ย้ายเครื่อง/ขึ้นโฮสต์ต้องคัดลอกเอง (BACKUP.md บอกไว้)
6. **สำรองอยู่เครื่องเดียวกันทั้งหมด** — เครื่องพัง/ไฟไหม้/ถูกขโมย = หายทั้งคู่ (BACKUP.md ระบุแล้ว) รอโฮสต์
7. **หน้าบริการ SSR เป็นอังกฤษก่อนแล้วสลับตามคุกกี้** (แบบแผน `LocaleProvider` ทั้งเว็บ) — Google เห็นเนื้อหาอังกฤษ · จะเปลี่ยนต้องทำระดับเว็บ (ข้อ 30)
