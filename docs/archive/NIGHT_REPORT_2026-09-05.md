## 3. ติดอะไร / ค้นพบอะไร

1. **Coral Pink (KOKO) ยังใช้รูปไม่ได้** — ไฟล์ทางการที่ส่งมาเป็นแบนเนอร์ที่ตัวเครื่องถูกตัดขอบ · ส่วนไฟล์เก่าที่มีอยู่ (`variant-coral-pink.webp`) เซสชัน 3 ก.ย. เคยปิดไว้เพราะ "มีรอยหยักขาวรอบขอบตอนแสดงจริง" — คืนนี้ลองเปิดใหม่และถ่ายจริง **รอยยังอยู่** (ดูภาพ `pair-g4pro-koko.png` ฝั่งขวา) → ปิดต่อ สีแสดงเป็น swatch · ทางแก้ครั้งหน้า: ตัดขอบใหม่แบบนุ่ม หรือหารูปอื่น
2. **บั๊กระบบที่เจอและแก้แล้ว**: สคริปต์เขียนทับไฟล์เดิมไม่ได้ (Windows EPERM) เพราะ sharp เก็บไฟล์ที่เพิ่งอ่านค้างในแคช → แก้ให้อ่านเป็น buffer + ปิดแคช (บันทึกในโค้ด กันคนต่อไปเจอซ้ำ)
3. **ขนาดตัวเครื่องในหน้าสินค้าเล็กลง** เมื่อใช้ canvas จัตุรัส 1000×1000 กับเครื่องทรงสูงแคบ (zero-pro ดูภาพเทียบ) — เป็นผลของสเปคที่คุณกำหนด ไม่ใช่บั๊ก · planner เตือนว่ากรอบการ์ดในแคตตาล็อกเป็น 4:5 ส่วน hero เป็นจัตุรัส ถ้าอยากให้เครื่องใหญ่ขึ้นมี 2 ทาง: (ก) เปลี่ยน canvas เป็น 4:5 หรือ (ข) ปรับกรอบ UI — **ยังไม่แตะ รอคุณดูภาพจริงแล้วตัดสิน**
4. Browser pane ยังอ่านเว็บ UWELL/Joiway ไม่ได้ (policy gate) — Joiway ได้มาเพราะแกะ API ของเว็บเอง, UWELL ได้เพราะคุณส่งลิงก์
