## 8. ความเสี่ยงและจุดต้องระวัง (อันตรายมากไปน้อย)

1. **กติกาการถาม (เจ้าของสั่ง 2026-09-11 — แทน "ถามแล้วพัก" ที่ยกเลิก):** ทดสอบคำถามเดียว "ถ้าทำผิด แก้กลับยากไหม และลูกค้าเห็นไหม" → แก้กลับง่าย + ลูกค้าไม่เห็น = ตัดสินเอง แล้วเขียนในรายงาน "ตัดสินเอง: … เพราะ …" · ต้องถาม: ประโยคใหม่ที่ลูกค้าอ่าน (ข้อ 30) · รสนิยม · คำไทยนอกตาราง · อะไรที่ขยับ layout/เดสก์ท็อป — คัดเหลือ 2-3 ทาง + ข้อดีข้อเสีย + ข้อแนะนำ **รวมส่งชุดเดียว** · ระหว่างรอ ทำทุกอย่างที่ไม่ติดคำถามต่อ เตรียมโค้ดได้แต่ยังไม่ commit ประโยคที่ยังไม่เคาะ · ถ้าไม่เหลืออะไรทำ → commit + push แล้วบอกว่ารออะไร
2. **OOM ยังไม่ปิดเคส** — ดูข้อ 4
3. **ห้าม merge / deploy / force push เอง** — Cowork หรือเจ้าของกด **และ Cowork ทำโดยไม่บอกในแชท** (PR #13 #14 #15) · revert ไม่ reset
4. **เดสก์ท็อป — เกณฑ์ขึ้นกับชนิดรอบ (ข้อ 9.1):** รอบที่แทนอังกฤษด้วยไทย = diff-rows (ยอมเลื่อนตามความสูงข้อความ) · รอบอื่น = 0-นอกมาสก์แบบเดิม · ทั้งสองแบบ: มาสก์จาก DOM ทุก build ที่เกี่ยว เขียนก่อนถ่ายภาพหลัง **ห้ามแก้หลังเห็นผล** · หน้าที่ไม่นิ่งเอง (8.4) ดู rows ก่อนตัวเลขรวม · **บทเรียนใหม่:** ตัววัดแบบ row-alignment พิสูจน์ไม่ได้เมื่อบล็อกข้อความอยู่กึ่งกลางข้างรูป (รูปไม่ใช่แถวซ้ำ) → ต้องใช้ตา designer · มาสก์แบบ `h1 ~ p` ไม่ถึง `<p>` ที่อยู่ใน div ลูก (ProductHero) · สระบน/วรรณยุกต์ไทยของหัวข้อใหญ่ล้นกล่อง 2–4px (pad 6 ไม่พอ)
5. **นิยาม agent ถูกอ่านตอนเปิดเซสชัน** — แก้ `.claude/agents/*.md` แล้วต้องเปิดเซสชันใหม่ · **`SendMessage` ไม่มีในเครื่องมือของตัวหลัก** — ต่อบทสนทนากับ agent เดิมไม่ได้ ต้องเปิด agent ใหม่ (รอบนี้ thai-copy รายงานยาวจนต้นรายงานหายในการแจ้งผล และ output file ว่าง → ต้องเปิดใหม่ให้ส่งซ้ำ) → **สั่ง agent ให้รายงานกระชับ และแยกงานใหญ่เป็น 2 agent**
6. **Browser pane ใช้ไม่ได้ในเครื่องนี้** — ใช้ `scripts/shot.js` · Windows ไม่มี Docker/WSL/Python/ffmpeg
7. **`heredoc`/`node -e` ที่มี backtick/escape/`\n` บนไฟล์ CRLF พัง** (รอบนี้ 2 ครั้ง: heredoc ที่มี `'` ในเนื้อไทย · pattern `\n` ไม่ match CRLF ทำให้ทั้งสคริปต์ไม่เขียนอะไรเลย) → **เขียนสคริปต์ด้วย Write tool ลง `_incoming/<รอบ>/` แล้วรัน `node ไฟล์` · สคริปต์แก้ไฟล์ต้อง normalize `\r\n`→`\n` ก่อน match แล้วแปลงกลับ**
8. **CRLF:** โปรเจกต์ `core.autocrlf=true` (รีโปเก็บ LF · working copy CRLF) · **Edit/Write tool และ `sed -i` บนเครื่องนี้เขียน LF** · `perl -pi -e 's/\\u00A0/…/'` กิน `\u` (เป็น escape ของ perl) → ก่อน commit ทุกครั้ง `git ls-files --eol <ไฟล์ที่แตะ>` แล้ว `perl -pi -e 's/\r?\n/\r\n/' <ไฟล์ w/lf>` + `git add --renormalize .` · git ไม่ทำให้ diff บวม (`--stat` = `--ignore-cr-at-eol`) แต่เจ้าของต้องการ working copy สม่ำเสมอ
9. **ปิดเซิร์ฟเวอร์ทดสอบต้องเจาะจง PID เสมอ — `taskkill //PID <pid> //F` · ห้าม `taskkill /IM node.exe`** · ปุ่มพรีวิวของเจ้าของรัน `next dev` พอร์ต 3000 → ถามก่อนปิด · **หยุด background shoot ด้วย TaskStop แล้วต้องไล่ปิด `bash shoot.sh`/`node shot.js`/headless chrome (`--user-data-dir=%TEMP%/okami-*`) ที่ค้างด้วย PID** (รอบนี้เหลือค้าง 3 process + chrome 2)
10. **`next build` ระหว่าง `next start -p 3412` รันอยู่ = ทับ .next ที่ server ใช้** · `verify:catalog --full` build ด้วย → ปิด server ก่อนเสมอ (checker ห้ามรัน)
11. **ชุดถ่ายภาพที่รันค้างอยู่ เขียนทับไฟล์ทีหลังได้** — โฟลเดอร์ชื่อใหม่ทุกรอบ (รอบนี้ base/after1(ลบแล้ว)/after2/after3) · อ่าน IHDR ทุก PNG ก่อนส่งผู้ตรวจ
12. **agent ตรวจภาพไม่มี Bash** — ครอปด้วย `crop-png.js` / ซอยด้วย `slice-phone.sh` ให้ก่อน · ภาพเต็มหน้าแรก 30,000px อ่านไม่ออก
