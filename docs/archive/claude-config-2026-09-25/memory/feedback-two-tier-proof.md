เจ้าของเคาะ 2026-09-14 (บันทึกถาวรใน docs/HANDOFF.md §8.0):
- **ชั้น A ข้อความล้วน** (แก้คำ/ประโยคในกล่องเดิม ไม่แตะ markup/CSS/element/component): build → นับจาก render → checker เทียบตารางทุกแถว → commit → push · **ไม่ถ่ายภาพ ไม่เรียก designer ต่อก้อน**
- **ชั้น B แตะโครง** (markup · CSS · เพิ่ม/ซ่อน element · component · word joiner): ถ่ายก่อน/หลัง 390+1440 + มาสก์จาก DOM + designer + checker เหมือนเดิม
- **ปิดรอบทุกรอบ:** ถ่ายทุกหน้าที่แตะ + designer 1 ครั้ง → รวมทุกจุด (รวมรายการตัดกลางคำ) → แก้ใน commit เดียว · รายการตัดกลางคำ**ไม่ใช่รอบแยก**อีกต่อไป

**Why:** ก้อนข้อความล้วนที่ผ่านมา ของที่ designer จับได้ทุกอย่างถูกยกไปแก้ทีหลังอยู่แล้ว การถ่าย/ตรวจภาพต่อก้อนจึงเสียเวลาโดยไม่เปลี่ยนผล (รอบ 30.4ก ถ่ายภาพ 4 ชุดใหญ่ ~1.8 GB)

**How to apply:** ก่อนเริ่มก้อน ให้จัดชั้นก่อน (A/B) แล้วเลือกขั้นตอนตามชั้น · ห้ามใช้ word joiner นอก 2 จุดที่อนุมัติแม้ในขั้นปิดรอบ · หลัก "ที่สุด" (พูดได้เฉพาะเมื่อทุกรุ่นที่เทียบมีตัวเลขในสเปกครบ) ใช้ทั้งไทยและอังกฤษ · ดู [[feedback-ask-level]] สำหรับกติกาถาม
