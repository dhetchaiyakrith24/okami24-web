เจ้าของสั่ง 2026-09-11 (กลางรอบ 30.3ข): กฎ "ถามเจ้าของแล้วยังไม่ตอบ = พักจุดนั้น ห้ามเดินแทน" ที่อยู่ใน HANDOFF 8.14 และคำสั่ง 30.3ข **ถูกยกเลิก** — Cowork เขียนเองโดยอ้างว่าเจ้าของสั่ง

กติกาที่ใช้แทน:
- ทดสอบคำถามเดียว: "ถ้าทำผิด แก้กลับยากไหม และลูกค้าเห็นไหม" → แก้กลับง่าย + ลูกค้าไม่เห็น = ตัดสินเอง แล้วเขียนในรายงานว่า "ตัดสินเอง: … เพราะ …"
- ตัวอย่างตัดสินเองได้: ย้อนได้ด้วย commit เดียว · ข้อเท็จจริงที่ตรวจจากข้อมูลจริงได้ · ทำตามกฎที่ล็อกใน THAI_STYLE · โครงสร้างโค้ดที่ลูกค้าไม่เห็น · เรื่องที่เจ้าของเคยตัดสินแบบเดียวกันแล้ว
- ต้องถาม: ประโยคใหม่ที่ลูกค้าอ่าน (ข้อ 30 บังคับ) · รสนิยม · คำไทยนอกตาราง · อะไรที่ขยับ layout/เดสก์ท็อป
- ถามให้ถูกวิธี: คัดเหลือ 2-3 ทางที่ดีพอกัน + ข้อดีข้อเสีย + ข้อที่แนะนำ · รวมเป็นชุดเดียว ไม่ทยอยถาม
- ระหว่างรอ: ทำทุกอย่างที่ไม่ติดคำถามต่อ · เตรียมโค้ดรอได้แต่ยังไม่ใส่ประโยคที่ยังไม่เคาะ · ถ้าไม่เหลืออะไรทำ → commit + push แล้วบอกว่ารออะไร

**Why:** รอบ 30.3ก/ข งานหยุดทั้งรอบเพราะรอคำตอบข้อเดียว · เจ้าของบอกเอง "ถามได้ครับ แต่งานต้อง flow ด้วย"
**How to apply:** ก่อนถาม ให้ผ่านการทดสอบคำถามเดียวก่อน · ทุกครั้งที่ตัดสินเอง ต้องมีบรรทัด "ตัดสินเอง: …" ในรายงาน 13.6 ข้อ 3 · ต้องแก้ HANDOFF 8.14 ให้ตรงในรอบที่แตะไฟล์นั้น ดู [[feedback-full-file-paths]]
