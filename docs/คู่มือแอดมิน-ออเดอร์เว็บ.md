📌 **ออเดอร์จากเว็บร้าน (สำหรับทีมงาน)**

**ลิงก์:** https://okami24.store/staff — ใช้รหัสทีมงานเดียวกับหน้าตรวจสลิป

**หน้าทีมงาน (มือถือ · 27/10)**
- หน้าแรก = **งาน**: ออเดอร์ที่รอทีมงานทั้งหมดอยู่ในหน้านี้เลย แยกตามขั้น **รอตรวจสลิป → รอส่งคลัง → รอใส่เลขพัสดุ** (ตัวเลขสีเหลือง = มีงานรอ) · แตะออเดอร์เพื่อเปิด
- ใต้รายการ: **ดูออเดอร์อื่น** = ยังไม่จ่าย · ส่งแล้ว/เสร็จ · ยกเลิก · ทั้งหมด · ท้ายหน้า = **ออกจากระบบ** · กล่อง 3 ใบด้านบนทุกหน้าหลัก = **ออเดอร์** (หน้างานนี้) · **ตรวจสลิป** (สลิปจาก LINE) · **Okami dev** (เชื่อม Shipnity · สต็อกจากคลัง · ดาวน์โหลด Excel · กลุ่ม LINE · เจ้าของ 28/10) · ทุกหน้ามีปุ่ม **← ชื่อหน้า** บรรทัดบนสุด = ย้อนกลับ
- เปิดออเดอร์ → กล่อง **"ขั้นต่อไป"** อยู่บนสุดเสมอ (มีของที่ต้องใช้ในขั้นนั้นครบ) · รายละเอียดอื่นพับไว้ แตะเพื่อเปิด · ยกเลิกอยู่ล่างสุด

**1. ออเดอร์มาถึงเราอย่างไร**
- ลูกค้าสั่งบนเว็บ → โอน → **แนบสลิปในหน้าออเดอร์ของลูกค้าเอง** → เว็บตรวจสลิปกับธนาคารทันที
- บอท **OKM ORDER** ส่งข้อความเข้ากลุ่ม **OKM Order**: เลขออเดอร์ · สินค้า · ยอด · ผลตรวจสลิป · ลิงก์เปิดออเดอร์ · **ตามด้วยรูปสลิปที่ลูกค้าแนบ** (เจ้าของ 26/10)
- รูปสลิปดูได้ในหน้าออเดอร์ด้วย (ตอนรอตรวจสลิปอยู่ในกล่อง "ขั้นต่อไป" · หลังจากนั้นอยู่ในแถว "รายละเอียด" · แตะรูปเพื่อเปิดรูปเต็ม) · **เก็บไว้ 90 วันแล้วระบบลบเอง** ผลตรวจสลิปยังอยู่ · สลิปที่โยนในกลุ่ม OKM Slip หรืออัปโหลดในหน้าตรวจสลิป ไม่เก็บรูป
- ผลตรวจสลิป: ✅ ผ่าน (เงินเข้าบัญชีร้าน ยอดตรง ไม่เคยใช้) · ⚠️ ต้องดูเอง (บอกเหตุผล) · ⏳ ระบบตรวจไม่ได้ (ดูแอปธนาคารเอง)
- ออเดอร์ที่ยังไม่จ่าย **ไม่มีข้อความเข้ากลุ่ม** ดูได้ที่ **ดูออเดอร์อื่น → ยังไม่จ่าย** ในหน้างาน · ไม่จ่ายใน 24 ชม. = ระบบยกเลิกเอง และ **ซ่อนจากทุกรายการ** (ไม่ได้ลบ — ลูกค้าถามมา เปิดด้วยลิงก์ `https://okami24.store/staff/orders/<เลขออเดอร์>` ได้ · ไฟล์ Excel ยังมีครบทุกใบ · เจ้าของ 26/10)

**2. ทำออเดอร์ทีละขั้น** (เปิดออเดอร์ → กดปุ่มในกล่อง "ขั้นต่อไป")
1. **ยืนยันยอดเงินแล้ว** — กดเมื่อสลิป ✅ หรือเมื่อเปิดแอปธนาคารร้านเห็นยอดเข้าจริงแล้ว · สลิป ⚠️/⏳ = ดูแอปธนาคารก่อนทุกครั้ง
   · กดแล้วออเดอร์ได้ **เลขรันของร้าน #0001, #0002 …** (สีส้มหน้าเลขออเดอร์ · ลูกค้าเห็นในหน้าออเดอร์ · อยู่ในไฟล์ Excel ช่อง "เลขรัน") · ออเดอร์ที่ไม่จ่ายไม่ได้เลข · เจ้าของ 26/10
   · **ก่อนกด เช็คของในหน้าคีย์ออเดอร์ของ Shipnity Max** (ปุ่ม "เพิ่ม" ของสี/กลิ่นนั้นเป็นสีฟ้า = มีของ · สีเทา = หมด) — หมด = ใช้กล่อง **สินค้าหมดหลังลูกค้าโอน** (ข้อ 3) แทน (เจ้าของ 24/10)
2. มีปุ่มส้ม **ส่งเข้าคลัง Shipnity** = กดปุ่มเดียวจบ: ออเดอร์เข้า Shipnity ของคลังเอง (ชื่อ ที่อยู่ เบอร์ สินค้า ค่าส่ง · ไม่ส่งสลิป) และบันทึกว่าส่งคลังแล้ว · ขึ้นแดง "ส่งไม่สำเร็จ" = กดใหม่อีกครั้ง หรือใช้แบบเดิมด้านล่าง (เจ้าของ 28/10 · แจ้งเตือน LINE เหมือนเดิม)
   ไม่มีปุ่มนี้ / เปิด **ส่งเองแบบเดิม** = กด **คัดลอกส่งคลัง** → วางส่งคลังแบบออเดอร์ LINE ปกติ → กด **ส่งรายการให้คลังแล้ว**
   (บรรทัดที่ขึ้น **[ไม่มีรหัสคลัง]** = สินค้านั้นยังไม่ผูกรหัส ถามเจ้าของร้านก่อนส่ง · ปุ่ม Shipnity ส่งไม่ได้เช่นกัน)
   · **หมายเหตุจากลูกค้า** (เช่น ฝากวางหน้าบ้าน) ไม่ได้ส่งเข้า Shipnity — ถ้าเกี่ยวกับการส่ง บอกคลังเอง
   · **คลังยกเลิกออเดอร์ใน Shipnity** (เช่น ของหมดกะทันหัน) = บอทแจ้งกลุ่ม OKM Order "⚠️ คลังยกเลิกออเดอร์ …" และหน้าออเดอร์ขึ้นแถบแดง · สถานะบนเว็บ**ไม่เปลี่ยนเอง** → คุยกับแอดมินคลัง แล้วแจ้งลูกค้า · เปลี่ยนสินค้า/คืนเงิน ใช้กล่อง **สินค้าหมดหลังลูกค้าโอน** (ข้อ 3) (เจ้าของ 28/10)
3. คลังให้เลขพัสดุ → ใส่ในช่อง **เลขพัสดุ** → กด **ส่งของแล้ว** — ลูกค้าเห็นเลขพัสดุในหน้าออเดอร์ของเขาทันที
4. ลูกค้าได้ของแล้ว → กด **ลูกค้าได้รับของแล้ว**

**3. ของหมดหลังลูกค้าโอน** (เจ้าของ 22/10 · ระบบในเว็บ 24/10)
- ในหน้าออเดอร์ กล่อง **สินค้าหมดหลังลูกค้าโอน** → ติ๊กสินค้าที่หมด → กด **แจ้งลูกค้าว่าสินค้าหมด** · อยากบอกลูกค้าเพิ่ม (เช่น "สีนี้หมดจากคลังค่ะ ขออภัยนะคะ") เขียนในกล่อง **ข้อความถึงลูกค้า** ของหน้าเดียวกัน (เจ้าของ 26/10: เหลือกล่องข้อความกล่องเดียว)
- ลูกค้าเลือก **คืนเงิน** ได้ 3 แบบ: พร้อมเพย์เบอร์ที่ใช้สั่ง · พร้อมเพย์เบอร์อื่น · เลขบัญชีธนาคาร + ชื่อธนาคาร (หน้าทีมงานเห็นเลขเต็ม)
- **โทรหรือทัก LINE บอกลูกค้าด้วย** — ลูกค้าจะเห็นในหน้าออเดอร์ของเขา ให้เลือก **เปลี่ยนเป็นสินค้าที่มีของราคาเท่ากัน** หรือ **รับเงินคืนเข้าพร้อมเพย์**
- ลูกค้าเลือกแล้ว บอทแจ้งในกลุ่ม OKM Order (ไม่มีเบอร์พร้อมเพย์ในกลุ่ม — ดูในหน้าออเดอร์)
- เลือกเปลี่ยนสินค้า → **เช็คของจริงที่คลังก่อน** → กด **ยืนยันเปลี่ยนสินค้าในออเดอร์** (รายการ + ข้อความส่งคลังเปลี่ยนตาม ยอดเงินเท่าเดิม) → ส่งคลังตามปกติ
  · ของที่ลูกค้าเลือกก็หมดอีก = เปิด **แจ้งใหม่** ให้ลูกค้าเลือกอีกครั้ง
- เลือกคืนเงิน → หน้าออเดอร์บอก **ยอดคืน + เบอร์พร้อมเพย์** → โอนคืนในแอปธนาคาร → ใส่ **เลขอ้างอิง** → กด **บันทึกว่าคืนเงินแล้ว**
  · บันทึกแล้วกด **เลือกรูปสลิปโอนคืนจากแอปธนาคาร** → **แนบสลิปให้ลูกค้าเห็น** — หน้าออเดอร์ของลูกค้าขึ้น "คืนเงินแล้ว" พร้อมสลิป
    (การ์ดนี้ค้างอยู่บนสุดของหน้าออเดอร์จนกว่าจะแนบ · แนบผิดรูป = เลือกรูปใหม่แทนได้ · รูปเก็บ 90 วันแล้วลบเอง)
  · คืนเฉพาะรายการที่หมด (ค่าส่งไม่คืน) รายการที่เหลือส่งตามปกติ · หมดทุกรายการ = คืนยอดทั้งหมด ออเดอร์ถูกยกเลิกเอง
  · ลูกค้าบอกทางโทรศัพท์/LINE ว่าขอเงินคืน ก็โอนแล้วบันทึกได้เลย ไม่ต้องรอลูกค้ากดในเว็บ

**4. ตรวจสลิปในกลุ่ม OKM Slip**
- สลิปจากลูกค้า LINE โยนรูปลงกลุ่ม **OKM Slip** ได้เลย บอทตอบผลภายในไม่กี่วินาที (ใช้แทนการอัปโหลดในหน้าตรวจสลิปได้)
- บอทบอกด้วยถ้าสลิปนั้นเคยตรวจแล้ว หรือผูกกับออเดอร์เว็บไหนอยู่ · บอทไม่ตอบข้อความตัวหนังสือ และไม่ตอบในกลุ่มอื่น

**5. ข้อควรรู้**
- ปุ่มกดได้เฉพาะขั้นที่ถูกลำดับ ถ้าขึ้น "ทำขั้นนี้ไม่ได้" = อาจมีคนกดไปก่อนแล้ว โหลดหน้าใหม่ดู
- ส่งของแล้วยกเลิกไม่ได้ · **ลูกค้าโอนแล้ว ยกเลิกได้เฉพาะกรณีของหมด** (เจ้าของ 22/10) — ใช้กล่องข้อ 3 แทนปุ่มยกเลิก
- **กดยกเลิก = ต้องเขียนเหตุผลถึงลูกค้า** (ลูกค้าเห็นในหน้าออเดอร์ว่ายกเลิกเพราะอะไร · เจ้าของ 24/10) · หมายเหตุทีมงานใส่หรือไม่ใส่ก็ได้
- กล่อง **ข้อความถึงลูกค้า** ในหน้าออเดอร์ = เขียนบอกลูกค้าได้ทุกเรื่อง (เช่น คลังส่งช้า 1 วัน) ลูกค้าเห็นในหน้าออเดอร์ทันที ส่งแล้วแก้ไม่ได้ · ข้อความอยู่ในหน้าออเดอร์ตลอด จึงไม่เขียนชี้ว่า "ด้านล่าง" (พอลูกค้าเลือกแล้ว ปุ่มให้เลือกจะเปลี่ยนเป็นสถานะ) · เรื่องด่วนยังต้องโทรหรือทัก LINE
- ข้อความแจ้งออเดอร์ในกลุ่มมีโควตาฟรีต่อเดือน ถ้าเงียบผิดปกติ ให้เปิดหน้า **งาน** ดูเอง ออเดอร์ทุกใบอยู่ในหน้านี้เสมอ
