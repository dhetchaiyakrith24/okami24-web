> เขียน 2026-09-17 (รอบเก็บบ้าน 9.3) สำหรับเจ้าของกดตามเองโดยไม่ต้องมี Code/Cowork · ทุกข้อ **[ตรวจแล้ว]** เว้นที่ติดป้าย
> ศัพท์: **Render** = เครื่องที่รันเว็บจริง (dashboard.render.com) · **Deploy** = การเอาโค้ดชุดหนึ่งขึ้นเว็บ 1 ครั้ง · **Rollback** = กดกลับไปใช้ deploy ครั้งก่อน · **tag** = ชื่อเล่นของจุดในประวัติโค้ด ใช้แทนรหัส 7 ตัวที่อ่านไม่ออก

## 1. เว็บพัง / ขึ้นของผิด → กลับไปเวอร์ชันก่อนหน้า (~2 นาที)

1. เข้า **https://dashboard.render.com** → คลิกบริการ **okami24**
2. เมนูซ้าย กด **Deploys** — จะเห็นรายการ deploy ทุกครั้ง เรียงใหม่สุดอยู่บน แต่ละแถวมีรหัส 7 ตัว (เช่น `857745b`) และวันเวลา
3. หาแถว**ก่อนหน้า**แถวบนสุดที่เป็นสีเขียว (Live) — คือเวอร์ชันที่ยังดีอยู่ก่อนของพัง
4. กดปุ่ม **⋯** (หรือ **Rollback**) ท้ายแถวนั้น → ยืนยัน **Rollback**
5. รอราว 2 นาที จนแถวใหม่บนสุดขึ้น **Live** สีเขียว → เปิด https://okami24.store ดูว่ากลับเป็นปกติ
6. แจ้ง Cowork/Code ว่า "ผม rollback ไปแล้ว" — โค้ดใน GitHub ยังเป็นของใหม่อยู่ ทีมต้องแก้แล้วค่อย deploy ใหม่

**ยังไม่เคยซ้อมจริง [รอเจ้าของ]** — ขั้น 9.4 ของรอบเก็บบ้าน: ซ้อม 1 ครั้งนอกเวลาขาย โดย Cowork เฝ้า

### 1ก. เว็บขึ้นเองหลัง merge (รอบ A "ต่อท่อ" 27/09) — ปิดชั่วคราว / ดูว่าขึ้น commit ไหน

ตั้งแต่รอบ A: merge งานที่แตะเว็บเข้า `main` แล้ว GitHub รันด่านเอง ผ่านครบ = สั่ง Render ขึ้นเว็บเอง (`.github/workflows/deploy.yml`) · **[ยังไม่ได้ลองบนมือถือ]**
- **ไม่ขึ้นเอง (Summary บอก "SKIP deploy" + เหตุผล):** merge ที่ไม่แตะเว็บ · merge ที่แก้ตัว workflow เองด้วย (แม้แตะเว็บ) · ด่านไม่ผ่าน · ยังไม่มีกุญแจ · main ขยับระหว่างตรวจ (รอบของ commit ใหม่ขึ้นแทน) — อยากให้ขึ้นเลย: Actions → deploy → **Run workflow** → branch `main` → ติ๊ก deploy → Run (ด่านรันก่อนเสมอ)
- **ดูว่าขึ้น commit ไหน สำเร็จไหม:** GitHub → รีโป okami24-web → แท็บ **Actions** → workflow **deploy** → แถวบนสุด → กล่องสรุป (Summary) บอก "DEPLOY started — commit xxxxxxx" หรือ "SKIP deploy — เหตุผล" · ขึ้นเว็บจริงสำเร็จไหม = Render → okami24 → **Events** (ขั้นนี้ GitHub ไม่เห็น)
- **ของพังหลังขึ้นเอง:** ทำข้อ 1 (Rollback) ก่อนเสมอ — แล้วค่อยแก้โค้ด · หลัง Rollback โค้ดใน `main` ยังเป็นของพัง: merge ที่แตะเว็บครั้งถัดไปจะดันของพังกลับขึ้นด้วย → บอกทีมให้ revert ก่อน หรือปิดตัวขึ้นเอง (ข้อถัดไป) จนกว่า revert จะ merge
- **ปิดตัวขึ้นเองชั่วคราว (ไม่ต้องแก้โค้ด):** GitHub → **Actions** → เมนูซ้ายเลือก **deploy** → ปุ่ม **⋯** มุมขวา → **Disable workflow** · เปิดคืน = ที่เดิม **Enable workflow** · ระหว่างปิด merge ไม่ขึ้นเว็บเลย (ขึ้นเว็บด้วยมือใน Render = Cowork)
- **ถอดกุญแจทิ้งถาวร:** GitHub → Settings → Secrets and variables → Actions → `RENDER_DEPLOY_HOOK_URL` → Remove · และ Render → okami24 → Settings → Deploy Hook → สร้างใหม่ (กุญแจเก่าใช้ไม่ได้ทันที)
