## 8. ความเสี่ยงและจุดต้องระวัง (อันตรายมากไปน้อย)

3. **desktop ห้ามขยับแม้พิกเซลเดียว** — พิสูจน์ด้วย `scripts/shot.js --width 1440 --desktop` 7 หน้า ×2 + มาสก์จาก DOM ทั้ง build ก่อน/หลัง (ข้อ 9.1) · **มาสก์ทุกชุดหมดอายุเมื่อข้อความเปลี่ยน** · **บทเรียน 30.3ก: ข้อความสั้นลงก็ทำให้ layout ขยับได้** (การ์ดใน rail สูงตามเนื้อ) — เวลาเขียนกฎมาสก์ให้คิดถึงกล่องที่ "สูงตามเนื้อ" ไม่ใช่แค่บรรทัดที่คำอยู่ · ถ้าต้องแก้โค้ดหลังเห็น diff ให้ build ใหม่ วัดมาสก์ build นั้นเพิ่ม แล้ว union ทั้งหมด (30.3ก ทำ 3 build) — **ห้ามแก้กฎ mask-eval** (30.2 · 30.3ก แก้ 0 ครั้ง)
