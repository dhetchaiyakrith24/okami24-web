# ก้อน 4 กู้การค้นรูป: ทำไมรูปหาย และแก้อะไรได้ (07/11)

## สรุป

รูปไม่ได้หายเพราะรูปพัง · รูปหายวันเดียวพร้อมหน้าเว็บ จึงเป็นเรื่องเดียวกับที่ Google จัดอันดับทั้งเว็บใหม่ · ของที่แก้ได้เหลือจุดเดียว คือเพิ่มรายชื่อรูปใน sitemap ซึ่งแก้แล้วในก้อนนี้ · ไม่สัญญาว่ารูปจะกลับมาเมื่อไหร่

## สาเหตุพร้อมหลักฐาน

| สาเหตุที่ตรวจ | ผล | หลักฐาน |
|---|---|---|
| รูปตกพร้อมเว็บทั้งเว็บ | **ใช่** [เชื่อว่า ระดับสาเหตุ · ตัวเลขตรวจแล้ว] | การแสดงผลรูป 26/10 = 213 → 27/10 = 0 วันเดียวกับเว็บ 179 → 28 (GSC-AUDIT 07/11 ข้อ 3) |
| เปลี่ยนชื่อรูปทำให้รูปหาย ในวันที่ตก | ไม่ใช่ [ตรวจแล้ว] | git 24–28/10 ไม่มีการลบหรือเปลี่ยนชื่อรูปใน `public/` (GSC-AUDIT ข้อ 6) |
| เปลี่ยนชื่อรูปหลังจากนั้น (ลายน้ำรุ่น 4 และ 5) | ถ้าไม่แก้จะเสีย จึงแก้แล้ว [ตรวจแล้ว] | PR 1280 ทำ 301 ทุกชื่อรูปเก่า · 11 ชื่อในโฟลเดอร์ `marbo-10k-clone` ยังเป็น 404 ตามที่บันทึกใน PR |
| SafeSearch หรือกล่องยืนยันอายุ | ไม่ใช่ [ตรวจแล้ว] | GSC-AUDIT ข้อ 6 |
| รูปไม่มี alt | ไม่ใช่สาเหตุ [ตรวจแล้ว] | รูปสินค้าบนหน้ามี alt ครบ · รูปที่ alt ว่างบนหน้าสินค้าคือช่องตัวเลือกบนมือถือ ซึ่งมีชื่อกำกับข้างรูปอยู่แล้ว ไฟล์เดียวกันมี alt ในแกลเลอรี |
| Google ไม่รู้จักไฟล์รูปตัวจริง | **แก้ได้ แก้แล้ว** [ตรวจแล้ว] | หน้าเว็บส่งรูปผ่านตัวย่อขนาด `/_next/image` · sitemap เดิมไม่มีรายชื่อรูปเลย · ก้อนนี้เพิ่ม 1,352 รูปจาก 98 หน้าสินค้า ทุกไฟล์ตรวจว่ามีจริง |

## อ่านผลค้นรูปจริง 07/11 [ตรวจแล้ว]

อ่านหน้า Google รูปภาพในเบราว์เซอร์ของแอป เว้นช่วงอย่างน้อย 25 วินาที ไม่เจอ CAPTCHA · เลื่อนลงอ่านราว 100 ผลต่อคำ ไม่ใช่ 100 อันดับที่นับครบเป๊ะ

| คำ | รูปเว็บเรา | ใครขึ้นแทน |
|---|---|---|
| relx lumi 18k | 0 | ร้านออนไลน์ไทยหลายร้าน หน้าสินค้าชื่อแบบ "รุ่น + จำนวนพัฟ + ราคา + กลิ่น" |
| esko bar switch 20k | 0 | ร้านออนไลน์ + คลิป YouTube Facebook Vimeo |
| infy 20k | 0 | ร้านออนไลน์ + Facebook Instagram Vimeo |

เจ้าของรูปอันดับต้น ๆ ไม่ได้ทำอะไรที่เราไม่มีเป็นพิเศษ · ต่างกันที่ความน่าเชื่อถือของเว็บในสายตา Google ซึ่งงานก้อนนี้แก้ไม่ได้

## ไม่ทำ

- ไม่เปลี่ยน alt เป็นภาษาไทยทั้งเว็บ: คำที่รูปเคยติดเป็นชื่อรุ่นอักษรละติน ซึ่ง alt เดิมมีอยู่แล้ว
- ไม่แตะหน้าตารูป ไม่เปลี่ยนชื่อไฟล์

## ตัวเช็คผล

เกณฑ์ = GSC-AUDIT ข้อ 8: รูปเฉลี่ย 20 แสดงผลต่อวันใน 7 วัน · อ่านจากหน้าจอ Search Console เพราะชุดส่งออกไม่มีข้อมูลรูป
