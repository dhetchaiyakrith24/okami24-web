### ทำเองได้ แม้อยู่นอก git หรือเป็นการลบ — รายการเดียว (คำสั่งงานรายสัปดาห์ · HANDOFF §17 · ตารางบน ชี้มาที่นี่ ห้ามเขียนซ้ำ)

0. **ของใน git** (git กู้คืนได้ · 13.3 #1): ไฟล์ ข้อ หรือแถวที่ล้าหลัง จบแล้ว หรือไม่มีไฟล์ live อ้าง — ทุกการลบในช่อง "แก้เองได้" ของตารางบน
   (ข้อบทเรียนที่เป็นกฎแล้ว · ของใน §16 ที่ git ยืนยันว่าจบ · `.claude/memory/` ที่ย้ายไปบ้านจริงแล้ว · สกิล/agent ที่ไม่มีใครใช้และไม่มีไฟล์ live อ้าง ·
   เอกสาร/บรีฟที่ล้าหลัง) · ตัวชี้ที่ชี้ของที่ลบ = `git show <sha>:<ไฟล์>` · เนื้อหาที่ยังใช้ย้ายไปบ้านจริงก่อนลบ
1. **branch ที่ merge เข้า main แล้ว ในเครื่องและบน GitHub** (TEAM_RULES 13.3 #1 · เจ้าของ 16/10 "ได้") — ในเครื่อง: commit ล่าสุดเก่ากว่า 7 วัน →
   `git branch -d` (branch ที่เพิ่งแตกอาจเป็นงานของแชทกลางวัน) · บน GitHub: `git push origin --delete <ชื่อ>` เมื่อปลาย branch อยู่ใน main
   (`git merge-base --is-ancestor`) และ commit ปลายเก่ากว่า 7 วัน และไม่มี PR ที่ยังเปิดจาก branch นั้น (branch ที่เพิ่งแตกจาก main ก็ "อยู่ใน main") · ไม่แตะ: branch ที่ worktree ใช้อยู่ · branch ที่เอกสารเอ่ยชื่อ (`main` `inbox` `gsc-data` · ของรอบที่ยังเปิด) ·
   ตัวกันของแอปปัด = ลงรายการ ไม่หาทางเลี่ยง
2. **worktree** → `git worktree prune` · ถอดได้เฉพาะ worktree ที่**จบแล้วครบทุกข้อ**: branch ของมัน merge เข้า main แล้ว (หรือไม่มี branch และ
   commit ที่ชี้อยู่ใน main) · `git -C <wt> status --porcelain` ว่าง (ไม่มีไฟล์ค้างหรือไฟล์นอก git) · ไม่มีโน้ต checker และไม่มีเครื่องทดสอบรันอยู่ ·
   ไม่ใช่ worktree ของแชทที่ยังทำงาน — ไม่ครบ = ลงรายการ ไม่ถอด · วิธีถอด: ถอดทางลัด `node_modules` ออกก่อน (`cmd /c rmdir <wt>\node_modules`
   = ถอดแค่ทางลัด) เช็คว่า `node_modules` ของโฟลเดอร์หลักยังครบ แล้วค่อย `git worktree remove --force` · ทางลัดอื่นข้างในถอดทีละตัวก่อน
3. **โฟลเดอร์งานในคอม — ย้าย ไม่ลบไฟล์** (เจ้าของ 14/10): ไฟล์/โฟลเดอร์งานที่วางกระจายในรากรีโป และโฟลเดอร์ `_incoming/` ที่ไม่มีไฟล์ live อ้าง
   และงานจบแล้ว (PR merge / รอบปิด · เว้น `house-*` ล่าสุด) → `C:\Users\dhetc\OKami24-archive\_incoming\` · โฟลเดอร์ว่างลบได้ ·
   ไม่แตะ: `Higgs Okm/` (ที่มาของรูปใน `scripts/process-images.map.json`) · `รายงานจากแอดมิน แชท/` · โฟลเดอร์ของเจ้าของ (Downloads · Desktop …
   = ลงรายการอย่างเดียว) · ของโปรเจกต์อื่น (กฎกลาง §12 ข้อ 32)
4. **ที่เหลือ = รายการลบชุดเดียวให้เจ้าของเลือก** (13.3 #1 · ลบเฉพาะที่เจ้าของ OK): branch ที่ยังไม่ merge (OK แล้ว = tag `archive/<ชื่อ>` ก่อนลบ) · โฟลเดอร์ใน `_incoming/` หรือที่เก็บ · โฟลเดอร์งานตั้งเวลาที่แอปไม่มีงานแล้ว ·
   **Artifacts ของโปรเจกต์นี้** ที่ไม่มีเอกสาร โค้ด หรือข้อมูลอ้าง URL + ไม่ได้แก้นานกว่า 14 วัน + เรื่องของมันตัดสินแล้วหรือจบแล้ว — แถวละ ชื่อ · วันที่ · ทำไม ·
   ลบด้วย URL จาก `action: list` เท่านั้น ลิงก์แบบอื่นเปิด `action: read` ดูชื่อก่อน (LESSONS พ31)

**รอบอัตโนมัติ (ก)** ทำได้เฉพาะข้อ 0–3 ที่ git ยืนยันว่าจบ · ข้อ 4 = ต่อท้ายรายงาน ไม่ลบเอง
