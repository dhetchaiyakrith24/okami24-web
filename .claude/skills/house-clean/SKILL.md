# /เก็บบ้าน

หลักเดียว (กฎกลาง §12 ข้อ 25 · แผนที่บ้านหัว TEAM_RULES): **เรื่องเดิม = เขียนทับหรือลบของเก่า · เรื่องใหม่ = เพิ่มได้ · เลิกใช้ = ลบ (git เก็บ)**
เป้าของการเก็บ = Friday มีอิสระมากขึ้น ไม่ใช่มีกฎมากขึ้น · ของที่จดต้องไม่ทำให้ต้องเดาว่าอะไรจริง

## ขั้น 1 — วัด (ไม่แก้อะไร)

1. `node scripts/house-check.js` — พิมพ์ในหน้าเดียว:
   - ขนาดกฎที่โหลดทุกแชท (5 ไฟล์) · HANDOFF · §16 · LESSONS · เทียบกับครั้งก่อน (`_incoming/house-last.json` ที่สคริปต์เก็บไว้เอง)
   - ตัวชี้ที่ชี้ไปไฟล์ที่ไม่มีแล้ว · เลข 13.x ที่ไม่มีในไฟล์กฎ · สคริปต์/เอกสาร/agent/สกิลที่ไม่มีใครอ้างถึง
   - ของใน `_incoming/` ที่ไม่มีไฟล์ใดอ้าง (ขนาด · วันที่) · worktree ค้าง · รอบใน `docs/rounds/` ที่ปิดแล้วแต่ inbox ยังมีสำเนา
   (ตัวเลขใช้บอกเจ้าของ ไม่ใช่ด่าน — เจ้าของ 01/10 "ไม่ต้องมีด่านวัดขนาด")
2. `rule-auditor` 1 ครั้ง — บรีฟ: เลนส์ 3 ข้อของเจ้าของ (ไม่แก้แล้วเละ · ไม่มัดมือชก · จัดการของเก่า) + ผลขั้น 1 เป็นจุดเริ่ม ·
   ขอตาราง 1 กฎ 1 แถว: ขัด / ตาย / ซ้ำ / บังคับวิธีโดยไม่กันพังจริง (เสนอผ่อน) / ข้อห้ามที่ทำเป็นตัวล็อกได้

## ขั้น 2 — รายงานให้เจ้าของเคาะ (ภาษาไทย · ไฟล์ใน `_incoming/house-<วันที่>/`)

ติดตรงไหน · ช้าตรงไหน · จะเพิ่ม/ลด/แก้อะไร (เลขข้อละบรรทัด) · เป้าหลังเก็บเป็นตัวเลข · ความเสี่ยงและวิธีถอย ·
ของที่จะลบซึ่ง git กู้ไม่ได้ = รายชื่อให้เจ้าของดูก่อน (13.3 #1) · **หยุดรอเจ้าของเคาะ**

## ขั้น 3 — ลงมือตามที่เคาะ

- PR แยกตามเรื่อง ถอยทีละเรื่องได้: ข้อความกฎ/เอกสาร · ตัวล็อก/hook (ใหญ่ = ชุดตรวจเต็ม) · ของรก · กฎกลาง (PR ใน `smogz-rules`)
- เรียงเลขข้อกฎใหม่ = ตารางเลขเก่า → เลขใหม่ในข้อความ commit + แก้ตัวชี้ทั้งรีโปในคราวเดียว
- **พิสูจน์ว่าไม่มีกฎหายเงียบ**: checker ไล่ทุกข้อเดิมว่าความหมายไปอยู่ไหน
- รั้ว: หน้าเว็บที่ลูกค้าเห็นต้องเหมือนเดิม (`node scripts/self-merge-check.js --base origin/main` = PASS) — ก้อนไหนเว็บเปลี่ยน = หยุด ถอย รายงาน
