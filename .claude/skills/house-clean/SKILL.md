# /เก็บบ้าน

หลักเดียว (กฎกลาง §12 ข้อ 25 · แผนที่บ้านหัว TEAM_RULES): **เรื่องเดิม = เขียนทับหรือลบของเก่า · เรื่องใหม่ = เพิ่มได้ · เลิกใช้ = ลบ (git เก็บ)**
เป้าของการเก็บ = Friday มีอิสระมากขึ้น ไม่ใช่มีกฎมากขึ้น · ของที่จดต้องไม่ทำให้ต้องเดาว่าอะไรจริง
คำตัดสินของเจ้าของเรื่องนี้ (15/10 · บ้านของมันคือสกิลนี้) — บ้านสะอาด 4 อย่าง: กฎไม่ขัด ไม่ซ้ำ ตัวชี้ไม่ตาย · ไฟล์ไม่โตเกิน ·
ไม่มีของค้าง/ไฟล์ขยะ · ตัวล็อกยังเปิด + % ทำตามกฎ

## แก้เองได้ / ต้องรอเจ้าของ (เจ้าของ 15/10 · กฎกลาง §12 ข้อ 28)

- **แก้แล้วรายงาน:** ตัวชี้ที่ชี้ไฟล์/ข้อที่ไม่มีแล้ว · ข้อความซ้ำที่เนื้อหาตรงกัน (รวมไว้บ้านเดียว) · ตัวล็อกที่ถูกปิด (เปิดกลับ) ·
  ช่อง "แก้เองได้" ของตาราง "เกลาทีละบ้าน" ข้างล่าง (เจ้าของ 15/10 "แก้และทำเลย") — ทุกอย่างอยู่ใน git ถอยได้
- **รอเจ้าของเลือก:** กฎที่ขัดกันเรื่องธุรกิจ รสนิยม หรือทิศงาน (เทคนิคล้วน = Friday เลือก 13.3) · กฎใหม่ · ลบของนอก git (13.3 #1)
- **ห้ามแตะเลย (รายงานได้อย่างเดียว):** กฎกลาง (เสนอเจ้าของ → PR ใน `smogz-rules`) · `docs/BUSINESS_SOURCE_OF_TRUTH.md` และไฟล์ราคา ·
  โฟลเดอร์ของเจ้าของ (`รายงานจากแอดมิน แชท/`) · ทุกอย่างใน `src/` และ `public/`
- คำถามถึงเจ้าของ = เฉพาะเรื่องที่เจ้าของตัดสินได้ · ทางเลือกเทคนิค (ตัวล็อก สคริปต์ วิธีตรวจ) Friday เลือกเอง (TEAM_RULES 13.3)

## (ก) รายสัปดาห์ — งานตั้งเวลา `okami24-house-weekly` (ไม่มีคนเฝ้า)

คำสั่งละครั้ง ไม่ต่อ `cd … &&` (คำสั่งอ่านอย่างเดียวอนุญาตไว้ใน `permissions.allow` ของ `.claude/settings.json` · ขั้นเขียน git ต้องให้งานอยู่โหมด Auto —
TEAM_RULES 13.6)

1. **วัด:** `node scripts/house-check.js` → เก็บผลที่ `_incoming/house-<YYYYMMDD>/house-check.txt` (ขนาดเทียบสัปดาห์ก่อน · ตัวชี้ตาย ·
   ไฟล์ที่ไม่มีใครอ้าง · ของค้างใน `_incoming` · worktree · ตัวล็อก · % ทำตามกฎ 7 วัน · โฟลเดอร์งานตั้งเวลาของโปรเจกต์นี้)
2. **rule-auditor ทุก 2 สัปดาห์** — เรียกเมื่อ `rule-audit.md` ล่าสุดใน `_incoming/house-*/` เก่ากว่า 13 วัน · 1 ครั้ง · บรีฟ = เลนส์ 3 ข้อ
   (ไม่แก้แล้วเละ · มัดมือ · จัดการของเก่า) + ผลข้อ 1 · เก็บผลที่ `_incoming/house-<YYYYMMDD>/rule-audit.md`
3. **เกลาทีละบ้าน** — ไล่ตาราง "เกลาทีละบ้าน" ครบ 6 บ้าน · แก้เฉพาะช่อง "แก้เองได้" (ข้อ 4) · ที่เหลือลงรายงาน
4. **แก้ที่แก้เองได้** (หัวข้อบน + ตาราง) ใน worktree แยก `git worktree add _incoming/wt-house-<YYYYMMDD> -b house-weekly-<YYYYMMDD> origin/main`
   — ห้ามสลับ branch ของโฟลเดอร์หลัก (แชทกลางวันอาจทำงานอยู่) · commit + push · เปิด PR · เสร็จแล้ว `git worktree remove` worktree นั้น
   - ทุกไฟล์เป็นเอกสารล้วน (13.7) = คำอธิบาย PR มี `Checker: SKIP docs-only (13.7)` → `node scripts/self-merge-check.js --pr <n>` ขึ้น `SMALL` → merge
   - มีไฟล์อื่น (สกิล agent กฎ) = เปิด PR ทิ้งไว้ให้แชทกลางวันส่ง checker ก่อน merge
   - ไม่มีอะไรต้องแก้ = ไม่สร้าง branch
5. **รายงาน:** ไฟล์เต็ม `_incoming/house-<YYYYMMDD>/report.md` (ไทย · ตัวเลขคัดจากไฟล์ผล · ผล 6 บ้าน บ้านละบรรทัด) + ข้อความสุดท้ายของแชทงาน =
   **สรุปไทย 5 บรรทัด**: (1) ตัวล็อก + % ทำตามกฎ (2) ขนาดเทียบสัปดาห์ก่อน (3) เกลาบ้านไหน แก้เองกี่จุด PR ไหน (4) ของค้าง/ขยะ
   (5) เรื่องที่พี่ต้องเลือก (ไม่มี = บอกว่าไม่มี) · เรื่องที่ต้องเคาะ = 1 บรรทัดใน `docs/รอพี่ตรวจ.md` (ใส่ใน PR ข้อ 4 — ไม่มี PR = เปิด PR เอกสารล้วน)
6. ตัวล็อก git ถูกปิด = ตั้งกลับ `.githooks` (session-sync ทำให้แล้วตอนเปิดแชท) แล้วรายงานบรรทัดแรก

## (ข) รอบเต็ม — เจ้าของสั่ง /เก็บบ้าน

1. **วัด:** ข้อ (ก) 1 + `rule-auditor` 1 ครั้งเสมอ (ตาราง 1 กฎ 1 แถว · 6 ชนิดผลตรวจ = ไฟล์ agent `rule-auditor`)
   · ถ้าเจ้าของถาม "ทำตามจริงกี่ %" "ช้าตรงไหน" = นับจากประวัติแชทในเครื่อง (`~/.claude/projects/<โปรเจกต์นี้>/*.jsonl` — ตัวอย่างสคริปต์
   และผล 15/10 = `_incoming/house-1510/`) + `gh pr list` / `gh run list` · แชทคลาวด์ไม่มีในเครื่อง = บอกข้อจำกัด
   · **เกลาทีละบ้าน** ครบ 6 บ้าน (ตารางบน) — ช่อง "แก้เองได้" ทำได้เลยในก้อนแรก
2. **รายงานให้เจ้าของเคาะ** (ไทย · ไฟล์ใน `_incoming/house-<วันที่>/`): ติดตรงไหน · ช้าตรงไหน · จะเพิ่ม/ลด/แก้อะไร (ข้อละบรรทัด) · ความเสี่ยงและวิธีถอย ·
   ของที่จะลบซึ่ง git กู้ไม่ได้ = รายชื่อให้เจ้าของดูก่อน (13.3 #1) · ถามเฉพาะที่ต้องเลือก ทีละเรื่อง พร้อมตัวอย่างที่เจ้าของเห็นเอง
3. **ลงมือตามที่เคาะ:** PR แยกตามเรื่อง ถอยทีละเรื่องได้ (ข้อความกฎ/เอกสาร · ตัวล็อก/hook = ใหญ่ ชุดตรวจเต็ม · ของรก · กฎกลาง = PR ใน `smogz-rules`)
   · เรียงเลขข้อกฎใหม่ = ตารางเลขเก่า → เลขใหม่ในข้อความ commit + แก้ตัวชี้ทั้งรีโปในคราวเดียว
   · **พิสูจน์ว่าไม่มีกฎหายเงียบ**: checker ไล่ทุกข้อเดิมว่าความหมายไปอยู่ไหน
   · รั้ว: หน้าเว็บที่ลูกค้าเห็นต้องเหมือนเดิม (`node scripts/self-merge-check.js --base origin/main` = PASS) — ก้อนไหนเว็บเปลี่ยน = หยุด ถอย รายงาน
