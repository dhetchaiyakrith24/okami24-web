 · ลองเรียก agent ทั้ง 10 ตัว (งานสั้นที่สุดที่พิสูจน์ว่าโหลดได้) + สกิลในรีโปทุกตัว บนคลาวด์ [ลองแล้ว] · ตัวไหนเรียกไม่ได้/อ้างไฟล์ที่ไม่มี/ขั้นตอนเก่า = แก้ หรือบอกเหตุ
 · สกิลของบัญชี (`anthropic-skills:handoff` ฯลฯ) ใช้บนคลาวด์ได้ไหม · ถ้าไม่ได้ ใช้ตัวในรีโปแทนได้ไหม
 · คำอธิบาย (description) ของสกิล/agent ตรงงานจริง ไม่ทับกันจนเรียกผิดตัว
 agent: checker

【ก้อน 5】ตรวจภาพรวมสามเหลี่ยม + ดูฝั่งการ์ตูนแบบอ่านอย่างเดียว (รายงานอย่างเดียว)
 แนวคิด (เจ้าของ 27/09): "อนุญาตให้ดูของการ์ตูนได้เพื่อมีอะไรผิดพลาด แต่ไม่ต้องแก้ของการ์ตูน รายงานก่อน"
 · ฝั่งเว็บ: มีอะไรที่เป็นของการ์ตูน/ของโปรเจกต์อื่นปนอยู่ไหม · มีกฎเว็บที่ควรเป็นกฎกลาง หรือกฎกลางที่เว็บก๊อปมาซ้ำนอก `.claude/rules/` ไหม · คำสั่งรอบ/สกิลของเว็บพึ่งของนอกรีโปเว็บไหม
 · ฝั่งการ์ตูน: **ถ้าเครื่องมือ GitHub ในแชทนี้อ่านรีโป `merrumi-cartoon` ได้ (อ่านไฟล์ผ่านเครื่องมือ ไม่ clone เข้าเครื่องทำงาน)** → อ่าน แล้วรายงาน: ของเว็บปนไหม · สำเนากฎกลางตรงฉบับหลักไหม · ใช้ environment/ของร่วมกับเว็บตรงไหนบ้าง · **อ่านไม่ได้ = ไม่หาทางอื่น** เขียนรายการสิ่งที่ Javis ควรเปิดดูเองบน GitHub แทน
 · ผล = ตาราง: เจออะไร · ฝั่งไหน · ใครควรแก้ (เว็บ Friday / การ์ตูนตามที่เจ้าของสั่ง / กฎกลางเจ้าของเคาะ) · **ไม่แก้ของการ์ตูนและกฎกลาง**
 agent: rule-auditor (อ่านอย่างเดียว)

【ก้อน 6】กติกาคลาวด์ + ไฟล์ 2 ชุด + inbox (ตามคำตอบ Q1 Q2 Q5 Q7 Q8)
 · ลงคำตอบเจ้าของเป็นกฎเว็บ/ขั้นตอน (ที่เดียว ชี้ที่อื่น) · ถ้าเปลี่ยนสกิล round-close ให้รวมขั้นลบสำเนาใน inbox / สรุป `_incoming` ลง cloud-results
 · ถ้า Q1 = คงฉบับหลักบนคอม → เขียนว่า Friday อ่านฉบับไหน และเมื่อสองที่ไม่ตรงกันให้ทำอะไร
 agent: rule-auditor → checker

【ตรวจ】
 · หลักฐานไม่แตะเว็บ = `git diff --stat <จุดเริ่ม> -- src public` ว่าง · ไม่สแกนเว็บ ไม่รัน verify ชุดใหญ่ถ้าไม่ได้แตะของที่มันตรวจ
 · ทุกไฟล์ที่ลบ/ย้าย: ค้นชื่อทั้งรีโปแล้วไม่มีใครอ้าง (แสดงคำสั่ง + ผล) · ด่านที่อ่านรายการไฟล์ (eol-check · owner-rules-check · rules-move-check · central-rules-copy · self-merge-check) ยังผ่าน
 · rule-auditor ก่อน commit ฝั่งกฎ/สกิล · ไม่มีกฎซ้ำ/ขัดใหม่

【ส่งมอบ】
 · commit แยกตามก้อน (ถอยทีละก้อนได้) · push หลัง checker ผ่าน · doc-keeper อัปเดตที่เก็บสถานะที่เลือกในก้อน 3 (ยังเป็น §16 ก็ §16) · สรุปหลักฐานลง `docs/cloud-results/roundB-housekeeping.md`
 · **จุดหยุด 1 = ขั้น 0** · **จุดหยุด 2 = ชุดเดียว ภาษาไทยง่าย:** ตารางข้อที่ความหมายเปลี่ยน (กฎเว็บ) + ข้อเสนอกฎกลาง + ผลก้อน 5 + ตาราง ก่อน→หลัง ของก้อน 1 (ข้อไหนเจ้าของไม่ทัก = ทำตามตาราง) · แต่ละข้อมีคำแนะนำ 1 ทาง → เจ้าของตอบในแชทนี้ → ลงมือเฉพาะที่ตอบ
 · **merge หลังส่งจุดหยุด 2 แล้วเท่านั้น** · PR ที่ไม่แตะ `.claude/settings.json`/hook/`.github/`/`site-paths.js` = Friday merge เองตาม 13.7 · ที่แตะ = **PR แยก** ส่ง Javis (ลิงก์ compare + merge-pack)
 · รายงานปิดรอบภาษาไทยง่าย: ก่อน → หลัง (จำนวนไฟล์ · จำนวนกฎที่รวม/ตัด) · อะไรยังค้าง ใครทำ · ไฟล์/branch ที่สร้าง (ให้ Javis ลบ) · สิ่งที่ Javis ต้องทำฝั่งตัวเอง/ส่งต่อฝั่งการ์ตูนหรือกฎกลาง (ถ้ามี)
